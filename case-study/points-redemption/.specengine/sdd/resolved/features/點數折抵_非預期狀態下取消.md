# 釐清問題
會員在「訂單沒有任何生效中的折抵」或「訂單已送出」的狀態下按取消折抵，系統要怎麼反應？需求只說送出前可以取消，沒說這兩種狀態下的行為。

# 定位
R-POINTS_REDEMPTION-004、R-POINTS_REDEMPTION-005（模組 POINTS_REDEMPTION）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 兩者皆拒絕並回報錯誤（無折抵可取消／訂單已送出不可取消） |
| B | 「無折抵」時視為 no-op 不報錯；「已送出」時拒絕並回報錯誤 |
| C | 兩者皆視為 no-op，不報錯、不改數值 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-005 的 post_assertions；是否新增「無折抵時取消」Rule；Driver「取消折抵」方法的回傳型別。

Medium
