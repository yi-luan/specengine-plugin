# 釐清問題
會員輸入 0 點（或空白）並確認折抵時，系統要怎麼反應？需求未定義。

# 定位
R-POINTS_REDEMPTION-000 的 pre_conditions「欲折抵點數為正整數」（模組 POINTS_REDEMPTION）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕並回報錯誤：折抵點數必須大於 0 |
| B | 視為「不折抵」的無操作（no-op），不報錯，不改任何數值 |
| C | 視為取消既有折抵（若有） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-000 前置條件是否成立；是否新增零值 Rule；輸入驗證的測試 Scenario。
