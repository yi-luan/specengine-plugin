# 釐清問題
需求說折抵成功後立即扣除點數，且會員可在送出訂單前取消。若會員折抵後既沒送出訂單也沒取消就離開（關閉頁面、逾時、訂單被系統清除），已扣除的點數要怎麼處置？

# 定位
R-POINTS_REDEMPTION-000、R-POINTS_REDEMPTION-004；orders.status（模組 POINTS_REDEMPTION）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 訂單逾時或被清除時自動退回點數（等同系統代為取消折抵） |
| B | 點數維持扣除狀態，直到會員回來手動取消或送出訂單 |
| C | 改為「訂單送出時才真正扣點」，折抵階段只做預留（與需求字面「折抵成功後扣除」不同，需業務方確認） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
是否新增系統觸發的退點 Rule 與對應 Scenario；orders.status 的狀態集合；是否需要逾時機制（可能超出本模組範圍）。
