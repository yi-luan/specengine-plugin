# 釐清問題
「取消折抵」是只能整筆取消，還是可以只取消部分點數（例如折了 300 點，改為只折 100 點）？

# 定位
R-POINTS_REDEMPTION-004（模組 POINTS_REDEMPTION）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 只能整筆取消，要改點數就先取消再重新折抵 |
| B | 可指定取消的點數，退回該數值並相應調高應付金額 |
| C | 提供「修改折抵點數」操作取代部分取消（等同重複折抵題選 B 的取代語意） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-004 的 trigger_event 與 post_assertions；Driver 介面是否需要「取消點數」參數；與「重複折抵同一訂單」題互相牽動。

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
No

# 最終決策
- **決策選項**：C — 不提供部分取消；改點數一律用「重新折抵以新換舊」（與重複折抵題決策 B 一致）
