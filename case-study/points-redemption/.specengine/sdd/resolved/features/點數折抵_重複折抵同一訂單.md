# 釐清問題
同一張未送出的訂單已經有一筆生效中的折抵時，會員再次送出折抵（含快速連點、或改輸入不同點數）要怎麼處理？需求只描述一次折抵與一次取消。

# 定位
R-POINTS_REDEMPTION-000 的 pre_conditions；orders.redeemed_points（模組 POINTS_REDEMPTION）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕：一張訂單同時只能有一筆折抵，要改點數必須先取消再重新折抵 |
| B | 取代：新折抵自動取消舊折抵（退回舊點數、扣新點數），一筆訂單永遠只有最新一筆折抵 |
| C | 累加：多筆折抵疊加，總折抵點數仍受訂單金額與餘額上限約束 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-000 需新增「訂單尚無生效中折抵」前置條件或新增 Rule；快速連點的冪等性測試；orders 是否需要多筆折抵紀錄（影響 erm.dbml）。
