# 釐清問題
商家開檔時若開始時間不早於結束時間，或每位顧客限購件數大於限量件數，系統應如何處理？

# 定位
FLASH_SALE 模組，R-FLASH_SALE-001（開檔參數合法性）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 兩種情況都拒絕開檔 |
| B | 時間順序錯誤拒絕；限購大於限量則自動壓到限量件數 |
| C | 兩種情況都允許開檔 |

# 影響範圍
R-FLASH_SALE-001 的驗證規則與開檔測試資料。

# 優先級
Low

# 可複用慣例候選 (Reusable Policy Candidate)
Yes

# 來源
spec-01

# 最終決策
- **決策選項**：需求方指定「開始時間不早於結束時間 → INVALID_INPUT」，並同時包含 saleId 為空、quantity 或 perCustomerLimit 非正整數皆為 INVALID_INPUT。限購大於限量的部分由 spec-02 依最佳判斷裁示：拒絕開檔（INVALID_INPUT），不做靜默壓縮，避免商家輸入錯誤被默默改寫。此條為 spec-02 的判斷，非需求方原話，請於 flow-align 一併確認。
- **寫回位置**：矩陣 R-FLASH_SALE-001；terms.md 固定文案 FLASH-ERR-001
