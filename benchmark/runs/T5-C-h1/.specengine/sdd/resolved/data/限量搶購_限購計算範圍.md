# 釐清問題
同一位顧客的「每位顧客限購件數」要計算哪些保留？保留到期未付款而被釋放的件數，是否仍計入該顧客的限購額度？

# 定位
FLASH_SALE 模組，R-FLASH_SALE-006（限購計算）、R-FLASH_SALE-009（連點）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 只計入已成交（PAID）的件數 |
| B | 計入已成交與未到期的保留中件數；已釋放的不計 |
| C | 計入已成交、保留中與已釋放的全部件數 |

# 影響範圍
R-FLASH_SALE-004、006、009 的限購判斷與 getRemaining 口徑。

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No

# 最終決策
- **決策選項**：B。保留中與已成交都計入；已到期釋放的不計（釋放後可以再搶）。超過限購即整筆拒絕，回傳 LIMIT_EXCEEDED。
