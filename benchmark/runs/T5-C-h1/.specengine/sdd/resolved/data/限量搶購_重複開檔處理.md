# 釐清問題
商家對已存在的搶購編號再次開檔（重複 saleId）時，系統應如何處理？

# 定位
FLASH_SALE 模組，R-FLASH_SALE-019（重複開檔）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 一律拒絕，回傳「搶購編號已存在」，不改動既有搶購 |
| B | 參數與既有完全相同則回傳成功（冪等），參數不同則拒絕 |
| C | 覆寫既有搶購參數 |

# 影響範圍
開檔流程、flash_sale 唯一性。

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
Yes

# 最終決策
- **決策選項**：A。saleId 已存在 → 回傳 DUPLICATE_SALE，不改動任何資料。
- **寫回位置**：矩陣 R-FLASH_SALE-019；terms.md 固定文案 FLASH-ERR-002
