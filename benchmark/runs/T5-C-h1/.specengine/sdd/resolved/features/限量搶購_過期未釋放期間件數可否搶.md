# 釐清問題
保留已過到期時間、但排程尚未執行釋放的空窗期間，這些件數是否可以被其他顧客搶到？商品頁剩餘件數在這段時間如何計算？

# 定位
FLASH_SALE 模組，R-FLASH_SALE-013（釋放）、R-FLASH_SALE-017（剩餘件數）、R-FLASH_SALE-007（搶購）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 過期即視為可用：搶購時先回收已到期的 HELD 保留 |
| B | 必須等排程釋放後才可搶 |
| C | 商品頁顯示可搶、搶購時才回收 |

# 影響範圍
R-FLASH_SALE-007、013、017 與併發測試。

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No

# 來源
spec-01

---
# 最終決策
- **決策選項**：A（spec-02 依最佳判斷裁示，需求方授權）。搶購判斷與剩餘件數計算都把已到期但未被排程釋放的 HELD 保留視為已釋放。理由：與 Q1 的「已到期釋放的不計」一致；空窗期最長一分鐘，等排程會造成件數閒置，且顯示與可搶數不一致（C）風險較高。釋放（R-013）仍由排程執行，回收動作只是讓搶購判斷不依賴排程時刻。
- **寫回位置**：矩陣 R-FLASH_SALE-007、017
