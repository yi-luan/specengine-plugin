# 釐清問題
顧客搶購的件數大於目前剩餘件數時，系統應如何反應？

# 定位
FLASH_SALE 模組，R-FLASH_SALE-005（剩餘不足）、R-FLASH_SALE-000（主幹）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕，回傳剩餘件數不足 |
| B | 自動縮減為剩餘件數後保留 |
| C | 排入等候名單依序遞補 |

# 影響範圍
R-FLASH_SALE-005 的回應、搶購回傳格式。

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No

# 來源
spec-01

# 最終決策
- **決策選項**：A。剩餘件數等於搶購件數可以搶到；不足則整筆拒絕，回傳 SOLD_OUT，不部分保留。
