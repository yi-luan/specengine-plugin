# 釐清問題
搶購期間的起迄時刻，是否包含開始時刻與結束時刻本身？

# 定位
FLASH_SALE 模組，R-FLASH_SALE-002（期間外拒絕）、R-FLASH_SALE-000（主幹）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 開始含、結束不含（左閉右開） |
| B | 開始與結束皆含 |

# 影響範圍
R-FLASH_SALE-002 的期間判斷與邊界測試。

# 優先級
Low

# 可複用慣例候選 (Reusable Policy Candidate)
Yes

# 來源
spec-01

---
# 最終決策
- **決策選項**：A。現在 ≥ 開始時刻起可搶；現在 ≥ 結束時刻起不可搶。開始前回傳 NOT_STARTED，結束後回傳 ENDED。
