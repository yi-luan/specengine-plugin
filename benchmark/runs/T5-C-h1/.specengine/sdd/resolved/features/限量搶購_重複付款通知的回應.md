# 釐清問題
同一筆付款成功通知重複送達，而該保留已是成交狀態（PAID）時，對這次呼叫要回傳什麼？

# 定位
FLASH_SALE 模組，R-FLASH_SALE-012（重複付款通知）、R-FLASH_SALE-011（已釋放付款）、R-FLASH_SALE-015（找不到保留）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 回傳成功（冪等） |
| B | 回傳失敗並說明保留已成交 |
| C | 回傳成功並附重複通知標記 |

# 影響範圍
pay 的回傳型別與金流對接測試。

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
Yes

# 最終決策
- **決策選項**：A。已成交的保留再收到通知：回傳成功，不改任何東西。已釋放（EXPIRED 且未成交）的保留收到付款通知：回傳 HOLD_EXPIRED。找不到保留編號：回傳 HOLD_NOT_FOUND。
