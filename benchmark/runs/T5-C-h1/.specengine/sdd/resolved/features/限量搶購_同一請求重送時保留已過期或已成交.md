# 釐清問題
顧客搶購請求因逾時被重送（相同 requestId）時，若原保留已成交或已過期，系統應如何回應？

# 定位
FLASH_SALE 模組，R-FLASH_SALE-008（請求重送）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 一律回傳原保留目前狀態 |
| B | 已過期則拒絕，已成交仍回傳成功 |
| C | 非 HELD 一律回傳失敗 |

# 影響範圍
R-FLASH_SALE-008 的重送回應。

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
Yes

# 來源
spec-01

---
# 最終決策
- **決策選項**：需求方裁示：前一次成功 → 回傳同一張保留（同 holdId、同到期時間），不重複佔用件數、不重算限購；前一次失敗 → 當成新請求重新判斷。
- **寫回位置**：矩陣 R-FLASH_SALE-008
