# 釐清問題
百分比折扣算出來有小數時（例如 333 元打 10% = 33.3 元）要怎麼取整？需求說所有金額以整數元計算，但沒說是無條件捨去、四捨五入還是無條件進位；多張百分比券疊加時，是每張各自取整後加總，還是全部加總後才取整？

# 定位
R-MULTI_TENANT_COUPON-005（模組 MULTI_TENANT_COUPON）；ApplyResult.discount

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 每張 PERCENT 券的折扣額各自無條件捨去取整數（floor），再加總 |
| B | 每張 PERCENT 券的折扣額各自四捨五入取整數（round），再加總 |
| C | 所有 PERCENT 券的折扣額先以小數加總，最後一次無條件捨去 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-MULTI_TENANT_COUPON-005 的 post_assertions、折扣總額與折扣後金額的 Examples 數值
