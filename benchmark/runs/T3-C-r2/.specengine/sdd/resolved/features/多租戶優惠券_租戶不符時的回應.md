# 釐清問題
傳入的優惠券中有一張（或多張）屬於別的租戶（tenantId 與訂單不同）時，整筆結帳要怎麼回應？需求只說「優惠券只能用在同一租戶的訂單」，沒說是整筆拒絕還是只略過那張、其餘照套。若為拒絕，失敗原因 reason 的文案是什麼？

# 定位
R-MULTI_TENANT_COUPON-001（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕：ok=false，回傳失敗原因（請附文案） |
| B | 略過該張券，其餘合法的券照常套用，ok=true，applied 不含該券 |
| C | 整筆拒絕，但 reason 另附上是哪張券不符 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
