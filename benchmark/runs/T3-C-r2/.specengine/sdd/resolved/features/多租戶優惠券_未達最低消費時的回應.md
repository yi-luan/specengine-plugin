# 釐清問題
傳入的優惠券中有一張因訂單金額未達其最低消費而不能用時，整筆結帳要怎麼回應？整筆拒絕還是略過那張、其餘照套？若為拒絕，請附 reason 文案。

# 定位
R-MULTI_TENANT_COUPON-007（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕：ok=false，回傳失敗原因（請附文案） |
| B | 略過該張券，其餘合法的券照常套用，ok=true，applied 不含該券 |
| C | 整筆拒絕，但 reason 另附上是哪張券未達門檻 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-MULTI_TENANT_COUPON-007 的 post_assertions、失敗原因固定文案
