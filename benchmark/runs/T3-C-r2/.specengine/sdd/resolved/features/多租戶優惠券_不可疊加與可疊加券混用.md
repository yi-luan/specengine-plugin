# 釐清問題
一筆訂單傳入「一張不可疊加券 + 一張以上可疊加券」時，能不能一起用？需求只說不可疊加的券一張訂單只能用一張，沒說它能不能跟可疊加的券共用。若不能，請附 reason 文案。

# 定位
R-MULTI_TENANT_COUPON-003（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 不能混用，整筆拒絕：ok=false，回傳失敗原因（請附文案）；不可疊加的券只能單獨使用 |
| B | 可以混用：不可疊加只限制「同類不可疊加券不得超過一張」，可與可疊加券並用 |
| C | 只套用那張不可疊加券，可疊加券全部略過，ok=true |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍

# 優先級
