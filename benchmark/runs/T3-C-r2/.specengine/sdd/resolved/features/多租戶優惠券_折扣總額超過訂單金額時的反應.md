# 釐清問題
折扣總額（固定金額券，或固定金額與百分比券加總後）超過訂單金額時，系統怎麼反應？需求第 6 條說「固定金額折扣不得使訂單金額低於 0」，但沒說違反時是整筆拒絕、截斷讓折扣後金額為 0、還是略過造成超額的那張券。若為拒絕，請附 reason 文案。

# 定位
R-MULTI_TENANT_COUPON-006（模組 MULTI_TENANT_COUPON）；ApplyResult.finalAmount

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕：ok=false，回傳失敗原因（請附文案） |
| B | 自動截斷：折扣總額修飾為訂單金額，finalAmount = 0，ok=true |
| C | 略過造成超額的那張券（依傳入順序逐張累加，超額的不套），ok=true |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-MULTI_TENANT_COUPON-006 的 post_assertions、失敗原因固定文案
