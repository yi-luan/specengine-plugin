# 釐清問題
一筆訂單同時傳入兩張以上「不可疊加」的券時，系統怎麼反應？需求說不可疊加的券一張訂單只能用一張，但沒說多傳時是整筆拒絕、只套第一張、還是只套折扣最大的那張。若為拒絕，請附 reason 文案。

# 定位
R-MULTI_TENANT_COUPON-003（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕：ok=false，回傳失敗原因（請附文案） |
| B | 只套用傳入順序的第一張不可疊加券，其餘不可疊加券略過，ok=true |
| C | 只套用折扣額最大的那張不可疊加券，其餘略過，ok=true |
| Short | 自訂簡答 (<=5 字) |
