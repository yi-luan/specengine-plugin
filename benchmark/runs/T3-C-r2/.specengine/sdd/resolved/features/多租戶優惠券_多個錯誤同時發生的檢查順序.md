# 釐清問題
同一筆結帳同時有多種問題（例如一張券租戶不符、另一張過期、還有兩張不可疊加）時，失敗原因要回報哪一個？需求第 9 條只說「回傳失敗原因」（單數）。請指定固定的檢查順序，或是改成回報全部原因。

# 定位
R-MULTI_TENANT_COUPON-001～007（模組 MULTI_TENANT_COUPON）；ApplyResult.reason

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 依固定的檢查順序逐項檢查，回報第一個命中的失敗原因（請附順序） |
| B | 全部檢查完，把所有命中的失敗原因一起回報 |
| C | 依傳入券的順序逐張檢查，回報第一張有問題的券的原因 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
所有失敗 Rule 的優先序、多重錯誤的 Scenario Examples
