# 釐清問題
結帳時間 now 剛好等於 validFrom、或剛好等於 validTo 的那一刻，這張券算有效還是無效？需求只說「只能在期間內使用」，沒定義邊界。

# 定位
R-MULTI_TENANT_COUPON-002（模組 MULTI_TENANT_COUPON）；Coupon.validFrom／validTo

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 含頭含尾：validFrom ≤ now ≤ validTo 皆有效 |
| B | 含頭不含尾：validFrom ≤ now < validTo（validTo 當下已失效） |
| C | 不含頭不含尾：validFrom < now < validTo |
| Short | 自訂簡答 (<=5 字) |
