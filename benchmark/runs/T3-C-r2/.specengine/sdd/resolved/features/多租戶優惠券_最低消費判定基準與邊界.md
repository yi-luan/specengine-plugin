# 釐清問題
最低消費金額是用「折扣前的訂單金額」還是「扣掉其他券之後的金額」來判定？訂單金額剛好等於最低消費金額時算達標嗎？需求第 7 條只說「訂單金額未達者不能使用該券」。

# 定位
R-MULTI_TENANT_COUPON-007（模組 MULTI_TENANT_COUPON）；Coupon.minOrderAmount

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 以折扣前訂單金額判定；剛好等於算達標（orderAmount ≥ minOrderAmount） |
| B | 以折扣前訂單金額判定；剛好等於不算達標（orderAmount > minOrderAmount） |
| C | 以扣掉其他券之後的金額判定；剛好等於算達標 |
| Short | 自訂簡答 (<=5 字) |
