# 釐清問題
傳入的優惠券中有一張已過期（now 晚於 validTo）或尚未生效（now 早於 validFrom）時，整筆結帳要怎麼回應？是整筆拒絕還是略過那張？過期與尚未生效是否要用不同的失敗原因？若為拒絕，請附 reason 文案。

# 定位
R-MULTI_TENANT_COUPON-002（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕：ok=false，過期與未生效共用同一個失敗原因（請附文案） |
| B | 整筆拒絕：ok=false，過期與未生效各用不同失敗原因（請附兩個文案） |
| C | 略過該張券，其餘合法的券照常套用，ok=true |
| Short | 自訂簡答 (<=5 字) |
