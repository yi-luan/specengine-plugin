# 釐清問題
優惠券的最低消費金額 minOrderAmount 有設定、但值本身不合法（負數、非整數，例如 -100 或 99.5）時怎麼處理？矩陣只定義了折扣值 value 與有效期間字串的合法性（R-012 → INVALID_COUPON），沒定義 minOrderAmount 的合法範圍。另外 minOrderAmount = 0 算不算合法（等同無門檻）？

# 定位
Coupon.minOrderAmount／coupons.min_order_amount；R-MULTI_TENANT_COUPON-012（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 負數或非整數視為券本身不合法，整筆拒絕 INVALID_COUPON；0 合法（等同無門檻） |
| B | 負數、0 或非整數皆視為券本身不合法，整筆拒絕 INVALID_COUPON |
| C | 不檢查，照 R-007 規則比較（負數必定達標） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-MULTI_TENANT_COUPON-012 的 pre_conditions、erm.dbml coupons.min_order_amount note
