# 釐清問題
now、validFrom、validTo 其中之一不是合法的 ISO 8601 時間字串（無法解析）時怎麼處理？需求只規定格式為 ISO 8601，沒說收到壞字串的反應。若為拒絕，請附 reason 文案。

# 定位
ApplyInput.now／Coupon.validFrom／Coupon.validTo（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕整筆：ok=false，回傳失敗原因（請附文案；now 壞與券的時間壞可用不同文案） |
| B | 視為該券不在有效期間（走期間不符的處理） |
| C | 不檢查，交由執行環境的解析結果決定 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
新增 edge_case Rule 或併入既有輸入驗證 Rule、失敗原因固定文案
