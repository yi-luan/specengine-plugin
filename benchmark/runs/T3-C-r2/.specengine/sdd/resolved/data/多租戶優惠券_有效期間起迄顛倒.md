# 釐清問題
優惠券的有效期間起迄顛倒（validFrom 晚於 validTo）時怎麼處理？依現有規則它永遠不在期間內，會被回報為 COUPON_EXPIRED；但這其實是券資料本身錯誤，是否應改為 INVALID_COUPON？

# 定位
Coupon.validFrom／Coupon.validTo；R-MULTI_TENANT_COUPON-002、R-MULTI_TENANT_COUPON-012（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 視為券本身不合法，整筆拒絕 INVALID_COUPON（檢查順序在 COUPON_EXPIRED 之前） |
| B | 維持現狀，自然落入 COUPON_EXPIRED |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-MULTI_TENANT_COUPON-012 的 pre_conditions、erm.dbml coupons.valid_from／valid_to note

Low
