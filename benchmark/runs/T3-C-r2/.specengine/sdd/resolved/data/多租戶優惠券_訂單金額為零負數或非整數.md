# 釐清問題
orderAmount 為 0、負數、或非整數（例如 99.5）時怎麼處理？需求第 12 條說所有金額以整數元計算，但沒說收到不合法金額時是拒絕還是照算。若為拒絕，請附 reason 文案。

# 定位
ApplyInput.orderAmount／orders.amount（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 0、負數、非整數一律拒絕：ok=false，回傳失敗原因（請附文案） |
| B | 0 視為合法訂單（可結帳、折扣為 0），負數與非整數拒絕 |
| C | 不檢查，照算（非整數依小數規則處理） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
新增 edge_case Rule、erm.dbml orders.amount 約束、失敗原因固定文案
