# 釐清問題
優惠券本身的折扣值不合法時怎麼處理？例如 PERCENT 的 value 為 0、負數或大於 100；FIXED 的 value 為 0 或負數；或 value 非整數。需求沒定義 value 的合法範圍與違反時的反應。若為拒絕，請附 reason 文案。

# 定位
Coupon.value／coupons.value（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕整筆：PERCENT 須在 1～100、FIXED 須 > 0、皆須為整數，否則 ok=false 回傳失敗原因（請附文案） |
| B | 略過不合法的券，其餘照套，ok=true |
| C | 不檢查，照算 |
| Short | 自訂簡答 (<=5 字) |
