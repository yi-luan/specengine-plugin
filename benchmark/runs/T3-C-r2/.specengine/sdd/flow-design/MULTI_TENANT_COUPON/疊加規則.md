# 疊加規則

資格都過了，再看這批券能不能一起用：不可疊加的券只能單獨用一張；可疊加的券可以多張一起用。

- rule_id：R-MULTI_TENANT_COUPON-000、003、004、008、013（沿用）

```mermaid
flowchart TD
  A[資格驗證皆通過] --> B{不可疊加券有幾張？}
  B -- 兩張以上 --> X1[拒絕 NOT_STACKABLE<br/>R-003]
  B -- 一張 --> C{另外還有可疊加券？<br/>R-008}
  C -- 有 --> X2[拒絕 NOT_STACKABLE<br/>不可疊加只能單獨用 R-008]
  C -- 沒有 --> D[單張不可疊加券單獨使用<br/>R-000]
  B -- 零張 --> E[全部為可疊加券，全部一起套用<br/>R-004]
  D --> F[進入「折扣計算與成交」]
  E --> F
```

## 白話複述
1. 兩張以上不可疊加的券一起傳 → 整筆拒絕，原因 NOT_STACKABLE（R-003）。
2. 一張不可疊加券加上一張以上可疊加券 → 整筆拒絕，原因 NOT_STACKABLE（R-008）。
3. 只有一張不可疊加券 → 可以單獨使用（R-000）。
4. 全部都是可疊加券 → 全部一起套用（R-004）。
5. 檢查順序依 R-013（沿用）。
