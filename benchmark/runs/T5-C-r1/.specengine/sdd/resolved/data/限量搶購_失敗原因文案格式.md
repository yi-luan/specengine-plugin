# 釐清問題
操作失敗時回傳的「原因」（Result 的 reason 字串）要用什麼格式？目前已知的失敗情境有：檔次不存在、未開始、已結束、剩餘不足（售完）、超過限購、件數不合法、保留不存在、保留已到期／已釋放、保留已成交、搶購編號重複、開檔參數不合法。

# 定位
Result.reason（所有失敗回傳）、terms.md 固定文案；模組 FLASH_SALE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 英文大寫代碼，一情境一碼，例如：SALE_NOT_FOUND、SALE_NOT_STARTED、SALE_ENDED、SOLD_OUT、LIMIT_EXCEEDED、INVALID_QTY、HOLD_NOT_FOUND、HOLD_EXPIRED、ALREADY_PAID、SALE_EXISTS、INVALID_SALE。機器好判斷、前端自行翻譯。 |
| B | 繁體中文短句，例如：「找不到搶購檔次」「搶購尚未開始」「搶購已結束」「已售完」「超過限購件數」「件數不合法」「找不到保留」「保留已到期」「保留已成交」「搶購編號重複」「開檔參數不合法」。直接可顯示給人看。 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
所有 Result 失敗回傳、terms.md 固定文案節、所有失敗 Scenario 的 Then 步驟
