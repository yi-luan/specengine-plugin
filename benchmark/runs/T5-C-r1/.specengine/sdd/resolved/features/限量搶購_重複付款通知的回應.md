# 釐清問題
同一筆付款通知重複送達，也就是保留已經「已成交」之後又收到同一張保留的付款成功通知，系統要回成功還是失敗？需求說「同一筆付款通知可能重複送達」，但沒說第二次要回什麼。

# 定位
R-FLASH_SALE-002、holds.status、FlashSale.pay；模組 FLASH_SALE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 回傳成功（冪等）：狀態維持已成交，不做任何改變。金流重送時看到成功就不會再送，最省事。 |
| B | 回傳失敗（已付款）：告知該保留已成交。金流端需能辨識這種失敗不是真的失敗。 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
pay 回傳值、重複通知相關測試案例

# 優先級
High
