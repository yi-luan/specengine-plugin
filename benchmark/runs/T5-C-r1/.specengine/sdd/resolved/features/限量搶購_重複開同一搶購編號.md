# 釐清問題
商家用已經存在的搶購編號再開一檔，系統該怎麼反應？

# 定位
R-FLASH_SALE-001、flash_sales.sale_id、FlashSale.openSale；模組 FLASH_SALE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕：回傳失敗，原檔次完全不變。避免開賣中被覆寫造成件數混亂。 |
| B | 覆寫：以新設定取代舊檔次，剩餘件數重設為新的限量件數。既有保留與成交紀錄如何處理需另行釐清。 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
openSale 回傳值、flash_sales 寫入策略、開檔相關測試案例

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
Yes
