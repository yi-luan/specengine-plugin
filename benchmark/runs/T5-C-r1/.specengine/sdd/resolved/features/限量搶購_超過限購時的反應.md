# 釐清問題
顧客這次搶購的件數加上他先前已佔用的件數會超過限購件數（例如限購 3 件，已佔 2 件，這次要 2 件），系統該怎麼反應？

# 定位
R-FLASH_SALE-006（超過限購）、FlashSale.grab；模組 FLASH_SALE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕：回傳失敗，不建立保留。顧客可改件數重搶。 |
| B | 截到限購上限：只保留還能買的件數（上例保留 1 件），回傳成功。 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
customer_quotas.used_qty、holds.qty、grab 的成功／失敗判定與測試案例
