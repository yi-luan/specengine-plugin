# 釐清問題
「每位顧客限購件數」要怎麼累計？顧客搶到但沒付款、到期被釋放的件數，還算不算在他的限購額度裡？例如限購 2 件：顧客搶 2 件沒付款、到期釋放後，能不能再搶 2 件？

# 定位
R-FLASH_SALE-000、R-FLASH_SALE-006、customer_quotas.used_qty；模組 FLASH_SALE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 只算「保留中」與「已成交」：到期釋放後額度還回來，顧客可再搶。對顧客友善，但需在釋放時同步扣回額度。 |
| B | 曾經搶到就算：包含已釋放的保留，額度不還回。防止顧客反覆佔位不付款，實作上額度只增不減。 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
customer_quotas.used_qty 的增減時機、sweep 釋放時的副作用、限購相關測試案例

High

# 最終決策
- **決策選項**：A。需求方補充：「保留中與已成交都算；已到期釋放的不算（釋放後可以再搶）。」
- **寫回位置**：矩陣 R-FLASH_SALE-003（釋放時累計佔用件數扣回）、新增 R-FLASH_SALE-017（釋放後可再搶）；erm.dbml customer_quotas.used_qty note
