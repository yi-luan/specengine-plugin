# 釐清問題
時間剛好等於邊界時刻時算哪一邊？有三個邊界：(1) 現在時間剛好等於開始時間能不能搶；(2) 剛好等於結束時間能不能搶；(3) 剛好等於保留到期時間，這張保留算不算已到期（影響能否付款、排程是否釋放）。

# 定位
R-FLASH_SALE-002、R-FLASH_SALE-003、R-FLASH_SALE-007、R-FLASH_SALE-008；模組 FLASH_SALE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 半開區間：開始時刻可搶、結束時刻不可搶（搶購期間 = [開始, 結束)）；到期時刻即視為已到期（現在 >= 到期時間就不能付款、排程會釋放）。與 Store 的 px「經過 px 毫秒（含）即失效」一致。 |
| B | 全部包含：開始時刻與結束時刻都可搶（[開始, 結束]）；到期時刻當下仍可付款，排程只釋放「現在 > 到期時間」的保留。 |
| Short | 自訂簡答 (<=5 字) |
