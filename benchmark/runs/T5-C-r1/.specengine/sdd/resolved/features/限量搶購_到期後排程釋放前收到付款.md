# 釐清問題
保留已經到期，但排程還沒跑到、還沒把它釋放（排程每分鐘一次，最多有約一分鐘空窗），這時付款成功通知送達了，這張保留要不要成交？

# 定位
R-FLASH_SALE-002、R-FLASH_SALE-003、holds.status、FlashSale.pay；模組 FLASH_SALE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕，視同已到期：只要現在時間已過到期時間就不成交，不管排程跑了沒。規則單純、「10 分鐘」是硬期限；但顧客可能已付款卻沒成交，需由金流退款（退款不在本系統範圍）。 |
| B | 仍成交：只要排程還沒釋放、保留還在「保留中」，付款就算數。對顧客友善，但實際有效期限會比 10 分鐘多出最多約一分鐘且不固定。 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
pay 的前置判定、holds.status 轉換條件、到期付款相關測試案例

# 最終決策
- **決策選項**：A。需求方補充：「以付款當下時間判斷：到期時刻（含）之後一律拒絕，回 `HOLD_EXPIRED`，即使排程還沒釋放；這張保留之後由排程照常釋放。」
