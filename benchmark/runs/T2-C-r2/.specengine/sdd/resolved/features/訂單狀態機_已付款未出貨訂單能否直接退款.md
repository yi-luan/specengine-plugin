# 釐清問題
需求第 6 點說「已出貨」的訂單可以申請退款。已付款但還沒出貨的訂單，客戶直接申請退款（不走取消）時，系統要怎麼反應？

# 定位
R-ORDER_STATE_MACHINE-007～009 的狀態前置條件（Order.status = PAID 時 refund）；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕，回傳失敗原因（狀態不允許），要退錢請走取消 |
| B | 允許，規則同已出貨訂單的退款（可分多次、累計達已付金額變已退款） |
| C | 允許但只能一次全額退款，退完變已取消 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
refund() 的狀態檢查、對應 Scenario

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No

# 來源
spec-01

---
# 最終決策
- **決策選項**：A。已付款未出貨不能直接退款，要走取消；reason 固定 INVALID_TRANSITION。
- **寫回位置**：矩陣新增 R-ORDER_STATE_MACHINE-013
