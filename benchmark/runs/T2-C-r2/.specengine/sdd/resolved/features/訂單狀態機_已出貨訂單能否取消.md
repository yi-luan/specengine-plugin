# 釐清問題
需求第 4 點只說「已建立或已付款」的訂單可以取消，沒提已出貨的訂單。已出貨後客戶要取消，系統要怎麼反應？

# 定位
R-ORDER_STATE_MACHINE-005／006 的狀態前置條件（Order.status = SHIPPED 時 cancel）；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕，回傳失敗原因（狀態不允許） |
| B | 允許取消，視同全額退款，狀態改為已退款 |
| C | 允許取消，狀態改為已取消並退還全部已付金額 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
cancel() 的狀態檢查、對應 Scenario

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No
