# 釐清問題
需求第 2 點說付款金額必須等於訂單金額。少付（例如訂單 1000 付 900）跟多付（付 1100）是否一律拒絕？是否允許分次付款累計到訂單金額？失敗原因文案是什麼？

# 定位
R-ORDER_STATE_MACHINE-003（pay 金額不符）；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 少付、多付一律拒絕，不允許部分付款，失敗原因為固定代碼 AMOUNT_MISMATCH |
| B | 少付拒絕；多付接受並只記訂單金額為已付金額 |
| C | 允許分次付款，已付金額累計等於訂單金額時才變已付款 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
pay() 的金額檢查、R-ORDER_STATE_MACHINE-003 post_assertions、固定文案

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
No
