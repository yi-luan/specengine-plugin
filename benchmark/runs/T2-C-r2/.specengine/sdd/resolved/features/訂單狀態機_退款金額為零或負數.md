# 釐清問題
申請退款時金額是 0 或負數，系統要怎麼反應？需求只規範累計不得超過已付金額，沒講下限。

# 定位
R-ORDER_STATE_MACHINE-007～009 的金額前置條件（refund amount ≤ 0）；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕，回傳失敗原因（金額不合法） |
| B | 0 元視為成功但什麼都不變（冪等），負數拒絕 |
| C | 0 與負數都視為成功、不改變任何欄位 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
refund() 的金額檢查、對應 Scenario
