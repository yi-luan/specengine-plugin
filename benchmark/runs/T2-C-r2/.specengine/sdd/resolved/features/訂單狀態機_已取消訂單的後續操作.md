# 釐清問題
訂單已取消之後，如果再對它付款、出貨、退款或再次取消，系統要怎麼反應？需求沒有寫。

# 定位
Order.status = CANCELLED 時的 pay／ship／refund／cancel；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 全部拒絕，回傳失敗原因（狀態不允許） |
| B | 再次取消視為成功（冪等，回傳原訂單），其餘拒絕 |
| C | 全部拒絕，但已取消訂單允許重新付款復活為已付款 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
四個操作函式的狀態檢查、對應 Scenario

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No

# 來源
spec-01

# 最終決策
- **決策選項**：A。已取消訂單的付款／出貨／退款／再取消全部拒絕，reason 固定 INVALID_TRANSITION。
