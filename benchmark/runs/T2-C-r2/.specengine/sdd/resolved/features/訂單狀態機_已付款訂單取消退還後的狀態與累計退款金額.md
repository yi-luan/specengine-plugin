# 釐清問題
需求第 5 點說已付款訂單取消時要退還全部已付金額。退還之後訂單狀態是「已取消」還是「已退款」？退還的金額要不要記進累計退款金額（refundedAmount）？已付金額（paidAmount）要不要歸零？

# 定位
R-ORDER_STATE_MACHINE-006 的 post_assertions（Order.status、Order.refundedAmount、Order.paidAmount）；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 狀態 CANCELLED（已取消）；refundedAmount = paidAmount；paidAmount 維持不變 |
| B | 狀態 REFUNDED（已退款）；refundedAmount = paidAmount |
| C | 狀態 CANCELLED；refundedAmount 維持 0、paidAmount 歸 0（不留退款紀錄） |
| Short | 自訂簡答 (<=5 字) |
