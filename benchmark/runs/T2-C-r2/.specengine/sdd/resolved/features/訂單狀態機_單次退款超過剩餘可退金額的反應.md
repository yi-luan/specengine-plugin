# 釐清問題
需求第 6 點說累計退款金額不得超過已付金額。當單次退款金額加上先前累計會超過已付金額時（例如已付 1000、已退 600，這次申請 500），系統是整筆拒絕，還是自動只退剩餘的 400？

# 定位
R-ORDER_STATE_MACHINE-008（refund 超過上限的反應）；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕不截斷，回傳失敗原因，累計退款金額不變 |
| B | 自動截斷至剩餘可退金額（本例退 400），成功並變為已退款 |
| C | 拒絕但回傳剩餘可退金額提示 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
refund() 的金額檢查、R-ORDER_STATE_MACHINE-008 的 post_assertions、Scenario Outline 邊界列

High
