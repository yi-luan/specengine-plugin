# 釐清問題
已建立（尚未付款）的訂單取消後，已付金額（paidAmount）與累計退款金額（refundedAmount）應該是多少？

# 定位
R-ORDER_STATE_MACHINE-005 的 post_assertions（Order.paidAmount、Order.refundedAmount）；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 兩者皆為 0（本來就沒付錢，也沒有退款） |
| B | paidAmount = 0，refundedAmount 記為訂單金額 |
| C | 沿用取消前的值不另外規範 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-ORDER_STATE_MACHINE-005 post_assertions、cancel() 實作、對應 Scenario

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
No

spec-01

- **決策選項**：A。paidAmount = 0、refundedAmount = 0。
