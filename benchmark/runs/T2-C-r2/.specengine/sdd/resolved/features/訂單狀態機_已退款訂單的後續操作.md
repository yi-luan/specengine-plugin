# 釐清問題
累計退款達到已付金額、狀態變成已退款之後，如果再對它退款、出貨、取消或付款，系統要怎麼反應？需求沒有寫。

# 定位
Order.status = REFUNDED 時的 refund／ship／cancel／pay；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 全部拒絕，回傳失敗原因（狀態不允許） |
| B | 再次退款視為成功但金額不變（冪等），其餘拒絕 |
| C | 全部拒絕，但允許取消（狀態改為已取消） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
四個操作函式的狀態檢查、對應 Scenario

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No

# 最終決策
- **決策選項**：A。已退款訂單的退款／出貨／取消／付款全部拒絕，reason 固定 INVALID_TRANSITION。
