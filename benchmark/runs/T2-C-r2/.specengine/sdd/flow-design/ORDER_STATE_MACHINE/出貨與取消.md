# 出貨與取消

已付款訂單出貨；已建立與已付款訂單取消；含已建立出貨、已出貨取消、重複出貨的失敗分支。

- rule_id：R-ORDER_STATE_MACHINE-004, 005, 006, 015, 016, 017

```mermaid
flowchart TD
  C[已建立 CREATED] --> S1([商家出貨]) --> S1x[失敗 INVALID_TRANSITION<br/>R-016]
  C --> X1([客戶取消]) --> X1ok[已取消 CANCELLED<br/>paid 0 / refunded 0<br/>R-005]
  P[已付款 PAID] --> S2([商家出貨]) --> S2ok[已出貨 SHIPPED<br/>金額欄位不變<br/>R-004]
  P --> X2([客戶取消]) --> X2ok[已取消 CANCELLED<br/>退還全部：refunded = paid<br/>paid 不變<br/>R-006]
  S2ok --> S3([再出貨一次]) --> S3x[失敗 INVALID_TRANSITION<br/>R-017]
  S2ok --> X3([客戶取消]) --> X3x[失敗 INVALID_TRANSITION<br/>R-015]
```

白話複述：
1. 已付款出貨 → 已出貨，金額欄位不變（R-004）；已建立出貨 → INVALID_TRANSITION（R-016）；已出貨再出貨 → INVALID_TRANSITION（R-017）
2. 已建立取消 → 已取消、兩金額 0（R-005）；已付款取消 → 已取消、refunded = paid、paid 不變（R-006）；已出貨取消 → INVALID_TRANSITION（R-015）
