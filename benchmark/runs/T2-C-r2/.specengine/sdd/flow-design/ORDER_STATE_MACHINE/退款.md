# 退款

已出貨訂單可分多次退款；含金額不合法、超過上限、未達／剛好達到已付金額，以及已付款、已建立訂單退款的失敗分支。

- rule_id：R-ORDER_STATE_MACHINE-007, 008, 009, 013, 014, 018

```mermaid
flowchart TD
  C[已建立 CREATED] --> R00([申請退款]) --> R00x[失敗 INVALID_TRANSITION<br/>R-018 通則]
  P[已付款 PAID] --> R0([申請退款]) --> R0x[失敗 INVALID_TRANSITION<br/>要退錢走取消 R-013]
  S[已出貨 SHIPPED] --> R1([申請退款 amount])
  R1 --> Q1{amount ≤ 0？}
  Q1 -- 是 --> R1x[失敗 INVALID_AMOUNT<br/>R-014]
  Q1 -- 否 --> Q2{refunded + amount 與 paid 比較}
  Q2 -- 大於 --> R2x[失敗 REFUND_EXCEEDS_PAID<br/>整筆拒絕不截斷 R-008]
  Q2 -- 小於 --> R3[維持 SHIPPED<br/>refunded 累加<br/>R-007]
  Q2 -- 等於 --> R4[已退款 REFUNDED<br/>refunded = paid<br/>R-009]
  R3 --> R1
```

白話複述：
1. 已出貨退款金額 ≤ 0 → INVALID_AMOUNT（R-014）
2. 累計 + 本次 > 已付 → REFUND_EXCEEDS_PAID，整筆拒絕不截斷（R-008）
3. 累計 + 本次 < 已付 → 維持已出貨、累計累加，可再退（R-007）
4. 累計 + 本次 = 已付（可多次累計達到）→ 已退款（R-009）
5. 已付款直接退款 → INVALID_TRANSITION（R-013）；已建立退款 → INVALID_TRANSITION（R-018）
