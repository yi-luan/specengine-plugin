# 釐清問題
需求第 8 條寫「失敗時回傳失敗原因」，但沒有說明失敗原因的形式，也沒有指定各失敗情況的文案。

# 定位
ORDER_STATE_MACHINE 模組 OrderResult 的 reason 欄位

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 只回傳中文說明文字，文案由規格逐條定義並記入 terms.md 固定文案 |
| B | 只回傳錯誤代碼（英文常數），中文說明由呼叫方轉譯 |
| C | 兩者並存：代碼與中文說明同時回傳 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
reason 欄位的型別、所有失敗分支的代碼，以及 terms.md 固定文案表。

# 優先級
Low

# 可複用慣例候選 (Reusable Policy Candidate)
Yes
