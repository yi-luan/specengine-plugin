# 釐清問題
需求第 5 條寫「已付款的訂單取消時，系統要退還全部已付金額」，但 Order 欄位中的「累計退款金額」定義為退款合計（第 6 條）。取消時的退款是否要計入 refundedAmount，需求沒有說明。

# 定位
ORDER_STATE_MACHINE 模組的 Order.refundedAmount 欄位語意，對應規則 R-ORDER_STATE_MACHINE-007（已付款取消）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 計入：取消時 refundedAmount 設為已付金額，之後仍可見退款合計；狀態為已取消 |
| B | 不計入：取消時 refundedAmount 維持 0，已付金額保留原值，退款僅體現於取消結果 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
Order 欄位語意、R-ORDER_STATE_MACHINE-006、007 的後置斷言，以及已取消訂單的退款合計查詢。

High

# 最終決策
- **決策選項**：A。取消後狀態為 `CANCELLED`，refundedAmount = paidAmount。已建立的訂單取消時 refundedAmount = 0、paidAmount = 0。
