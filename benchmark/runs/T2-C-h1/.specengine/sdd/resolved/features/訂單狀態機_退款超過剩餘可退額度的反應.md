# 釐清問題
需求第 6 條寫「累計退款金額不得超過已付金額」，但沒有說明當單次退款金額會使累計超過已付金額時，系統的反應。

# 定位
ORDER_STATE_MACHINE 模組的 refund 操作，上限為「已付金額 − 累計退款金額」

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕並報錯：回傳 ok 為 false 與失敗原因，訂單不被修改 |
| B | 自動截斷：退款金額修正為剩餘可退額度並繼續 |
| C | 忽略並警告：不修改訂單，回傳 ok 為 true 並附警告 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
refund 操作的超額分支、R-ORDER_STATE_MACHINE-012、以及上限邊界測試案例。
