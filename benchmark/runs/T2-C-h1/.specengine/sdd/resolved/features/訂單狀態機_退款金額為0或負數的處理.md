# 釐清問題
需求第 6 條寫「退款可以分多次」，沒有說明退款金額為 0 或負數時的行為。

# 定位
ORDER_STATE_MACHINE 模組的 refund(order, amount) 參數 amount 的下界

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕並報錯：回傳 ok 為 false 與失敗原因，訂單不被修改 |
| B | 視為無動作：回傳 ok 為 true 與原訂單，不報錯 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
refund 操作的參數驗證，以及 R-ORDER_STATE_MACHINE-008、009、011。

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
Yes

# 來源
spec-01

---
# 最終決策
- **決策選項**：A。拒絕，reason 固定為 `INVALID_AMOUNT`。
- **寫回位置**：矩陣 R-ORDER_STATE_MACHINE-011（退款金額非正整數）；R-008、009 前置條件改為「退款金額為正整數」
