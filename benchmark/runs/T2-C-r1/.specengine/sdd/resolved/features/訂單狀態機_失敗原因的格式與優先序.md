# 釐清問題
需求說失敗時要回傳「失敗原因」（reason 字串），但沒定義格式。失敗原因要用什麼格式？當一次操作同時踩到多種錯誤（例如對已取消訂單付款且金額又不對）時，要回哪一個？

# 定位
OrderResult.reason；全部 ok=false 的 Rule（R-ORDER_STATE_MACHINE-001／002／007 及釐清後新增的狀態防禦 Rule）；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 固定英文代碼（例如 INVALID_AMOUNT、INVALID_TRANSITION），檢查順序先狀態後金額，只回第一個踩到的 |
| B | 固定英文代碼，檢查順序先金額後狀態 |
| C | 繁體中文完整句子（例如「付款金額必須等於訂單金額」），多重錯誤全部串接 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
所有失敗分支的 Then 文案（terms.md 固定文案節）、各函式的檢查順序、Scenario 的 reason 斷言
