# 釐清問題
除了上述已單獨提問的情況外，還有幾種需求沒提到的狀態與操作組合：已付款訂單再付款一次、已出貨訂單再付款、已出貨訂單再出貨、已建立訂單直接退款。這些組合系統該怎麼反應？

# 定位
pay／ship／refund 的狀態前置條件（R-ORDER_STATE_MACHINE-000／002／005 延伸）；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 全部拒絕，回傳 ok=false 與失敗原因，訂單不變 |
| B | 重複同一操作（再付款、再出貨）視為冪等成功，跨狀態的（已建立退款）拒絕 |
| C | 各組合逐一另外定義（請在簡答補充） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
pay／ship／refund 的狀態防禦分支與對應 Scenario
