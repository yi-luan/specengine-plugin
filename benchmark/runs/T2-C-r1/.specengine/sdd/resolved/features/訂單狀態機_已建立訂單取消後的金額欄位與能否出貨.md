# 釐清問題
已建立（尚未付款）的訂單取消後，paidAmount 與 refundedAmount 應該是多少？另外，已建立但尚未付款的訂單可以直接出貨嗎？需求只說已付款的訂單可以出貨。

# 定位
R-ORDER_STATE_MACHINE-003；ship 的狀態前置條件；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 取消後 paidAmount=0、refundedAmount=0；未付款不能出貨，拒絕並回傳失敗原因 |
| B | 取消後 paidAmount=0、refundedAmount=0；未付款可以先出貨（貨到付款） |
| C | 取消後欄位不變；未付款不能出貨 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-003 的 post_assertions、ship 的狀態防禦 Scenario

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No
