# 釐清問題
需求只說「已建立或已付款」的訂單可以取消，沒有說已出貨的訂單能不能取消。對已出貨（SHIPPED）的訂單呼叫 cancel 時，系統該怎麼反應？

# 定位
R-ORDER_STATE_MACHINE-003／004 的狀態前置條件延伸；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕，回傳 ok=false 與失敗原因，訂單不變 |
| B | 允許取消，狀態改為 CANCELLED 並退還全部已付金額 |
| C | 允許取消但不退款，狀態改為 CANCELLED |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
cancel(order) 的狀態防禦分支、對應 Scenario 與失敗原因文案
