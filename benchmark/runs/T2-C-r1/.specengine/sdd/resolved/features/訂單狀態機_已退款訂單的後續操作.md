# 釐清問題
訂單已經是「已退款」（REFUNDED）之後，如果再呼叫 refund／ship／cancel／pay，系統該怎麼反應？

# 定位
R-ORDER_STATE_MACHINE-006 的後續狀態；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 四種操作全部拒絕，回傳 ok=false 與失敗原因，訂單不變 |
| B | 再次 refund 視為冪等成功（回傳同狀態訂單），其餘三種拒絕 |
| C | 允許 cancel（狀態改為 CANCELLED），其餘拒絕 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
pay／ship／cancel／refund 四個函式的狀態防禦、對應 Scenario

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No
