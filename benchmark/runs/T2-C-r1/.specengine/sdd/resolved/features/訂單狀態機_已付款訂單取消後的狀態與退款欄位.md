# 釐清問題
已付款訂單取消時需求說要退還全部已付金額。退還之後訂單狀態要停在「已取消」還是變成「已退款」？退還的金額要不要記進累計退款金額 refundedAmount？

# 定位
R-ORDER_STATE_MACHINE-004；Order.status、Order.refundedAmount；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 狀態為 CANCELLED，refundedAmount 記為 paidAmount（退款金額有留痕） |
| B | 狀態為 CANCELLED，refundedAmount 維持 0，paidAmount 歸 0（以歸零表示已退還） |
| C | 狀態為 REFUNDED，refundedAmount 記為 paidAmount |
| Short | 自訂簡答 (<=5 字) |
