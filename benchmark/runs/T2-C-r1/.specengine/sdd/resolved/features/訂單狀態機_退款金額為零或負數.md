# 釐清問題
呼叫 refund 時退款金額是 0 或負數，系統該怎麼反應？需求只約束累計不得超過已付金額，沒有約束單次金額的下限。

# 定位
R-ORDER_STATE_MACHINE-005／006／007 的金額前置條件；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕，回傳 ok=false 與失敗原因，訂單不變 |
| B | 0 元視為無事發生而成功（回傳相同內容的新訂單），負數拒絕 |
| C | 不檢查，照常累加（負數會讓累計退款減少） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
refund 的輸入驗證、對應 Scenario、失敗原因文案

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
Yes
