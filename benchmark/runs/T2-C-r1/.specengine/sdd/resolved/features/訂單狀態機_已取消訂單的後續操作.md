# 釐清問題
訂單已經取消（CANCELLED）之後，如果再呼叫 pay／ship／refund／cancel，系統該怎麼反應？需求沒有定義已取消訂單的任何後續操作。

# 定位
R-ORDER_STATE_MACHINE-003／004 的後續狀態；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 四種操作全部拒絕，回傳 ok=false 與失敗原因，訂單不變 |
| B | 再次 cancel 視為冪等成功（回傳同狀態訂單），其餘三種拒絕 |
| C | 允許已取消訂單重新付款回到 PAID，其餘拒絕 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
pay／ship／cancel／refund 四個函式的狀態防禦、對應 Scenario

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No
