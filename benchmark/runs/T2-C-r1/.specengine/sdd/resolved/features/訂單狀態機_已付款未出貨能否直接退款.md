# 釐清問題
需求只說「已出貨」的訂單可以申請退款。已付款但尚未出貨（PAID）的訂單，可以直接呼叫 refund 退款嗎？

# 定位
R-ORDER_STATE_MACHINE-005／006／007 的狀態前置條件延伸；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 不行，拒絕並回傳失敗原因；要退錢必須走 cancel |
| B | 可以，比照已出貨訂單的退款規則（可分次、累計不得超過已付） |
| C | 可以，但只能一次全額退款，退完狀態為 REFUNDED |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
refund(order, amount) 的狀態防禦分支、對應 Scenario
