# 釐清問題
付款金額不等於訂單金額時（少付或多付），系統該怎麼反應？需求說付款金額「必須等於」訂單金額，但沒說不等時是整筆拒絕還是允許部分付款累計。

# 定位
R-ORDER_STATE_MACHINE-002；Order.paidAmount；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 少付與多付一律整筆拒絕，不允許部分付款，訂單不變 |
| B | 少付視為部分付款累計到 paidAmount（等於訂單金額時才變 PAID），多付拒絕 |
| C | 多付接受並記錄實付金額，少付拒絕 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
