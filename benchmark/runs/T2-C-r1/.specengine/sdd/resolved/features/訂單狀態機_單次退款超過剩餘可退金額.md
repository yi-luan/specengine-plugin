# 釐清問題
單次退款金額加上累計退款金額會超過已付金額時（例如已付 1000、已退 700、這次再退 500），系統該怎麼反應？上限是「已付金額 − 累計退款金額」，但超過時是整筆拒絕還是自動截到上限，需求沒說。

# 定位
R-ORDER_STATE_MACHINE-007；模組 ORDER_STATE_MACHINE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕不截斷，回傳 ok=false 與失敗原因，訂單不變 |
| B | 自動截斷到剩餘可退金額並成功，狀態變 REFUNDED |
| C | 照常成功但記錄警告（允許 refundedAmount 超過 paidAmount） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-007 的 post_assertions、refund 的邊界 Scenario Outline、失敗原因文案
