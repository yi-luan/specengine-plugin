# 釐清問題
百分比折扣（PERCENT）的 `value` 允許的數值範圍是什麼？需求只說「折扣百分比」，未說明是否可為小數（例如 12.5%）、是否必須介於 0 到 100 之間，以及超出範圍時系統如何反應。

# 定位
模組 COUPON｜Entity `coupons.value`（type = PERCENT 時）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整數百分比，範圍 1 至 100；超出範圍的優惠券建立或套用時拒絕並報錯 |
| B | 允許小數百分比（例如 12.5），範圍 0 至 100；超出範圍時拒絕並報錯 |
| C | 允許小數百分比，超過 100 時自動修飾為 100 並繼續 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
`coupons.value` 的型別（int 或 decimal）、R-COUPON-000 與 R-COUPON-004 的百分比計算、取整規則（見「百分比折扣取整方式」）、測試的邊界案例。
