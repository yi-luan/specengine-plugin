# 釐清問題
多張可疊加券的折扣加總後超過折扣前訂單金額時（例如兩張百分比券合計 120%，或百分比加固定金額超過訂單金額），需求未說明要如何處理。

# 定位
模組 COUPON｜Rule R-COUPON-005（同時影響 R-COUPON-004）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕整次套用，回傳失敗原因 |
| B | 截斷：折扣總額以折扣前訂單金額為上限，折扣後金額為 0，全部券視為已套用 |
| C | 依傳入順序逐張套用，超過上限的券不套用並列為未套用 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
`discount`、`finalAmount`、`applied` 的計算；是否需要新增「未套用原因」欄位（目前 ApplyResult 結構固定，只能靠 reason）。

# 優先級
High

Yes
