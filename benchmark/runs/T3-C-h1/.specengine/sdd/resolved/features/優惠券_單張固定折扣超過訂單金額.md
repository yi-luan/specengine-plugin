# 釐清問題
單張固定金額折扣（FIXED）的面額大於折扣前訂單金額時（例如訂單 500 元，券面額 800 元），需求第 6 條要求訂單金額不得低於 0，但未說明系統要怎麼做。

# 定位
模組 COUPON｜Rule R-COUPON-001

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕該券並回傳失敗原因，整次不套用 |
| B | 截斷：折扣金額以折扣前訂單金額為上限，折扣後金額為 0，該券仍視為已套用 |
| C | 忽略：不套用該券，回傳原訂單金額，並附警告 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
`discount` 與 `finalAmount` 的計算、`applied` 是否包含該券、R-COUPON-005 中固定折扣與百分比合計的處理。
