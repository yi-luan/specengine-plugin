# 釐清問題
需求第 12 條規定所有金額以整數元計算，但百分比折扣的計算結果（例如 1001 元的 15%，為 150.15 元）可能不是整數。百分比折扣的折抵金額應如何取整？

# 定位
模組 COUPON｜Rule R-COUPON-000（同時影響 R-COUPON-004、R-COUPON-005）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 無條件捨去（floor），對消費者有利 |
| B | 四捨五入（round），誤差最小 |
| C | 無條件進位（ceil），對商家有利 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
所有百分比折扣的 `discount` 與 `finalAmount` 計算、R-COUPON-004 多張百分比加總後的取整時機（逐張取整或加總後取整）、相關測試的期望值。

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
Yes
