# 釐清問題
`ApplyResult` 失敗時的 `reason` 文字，是要用固定文案（逐字一致，寫入 terms.md「固定文案」節），還是由實作自由撰寫？需求第 9 條只要求回傳失敗原因。

# 定位
模組 COUPON｜Rule R-COUPON-002、R-COUPON-003（失敗的 reason 欄位）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 固定文案：每種失敗原因定義一組固定文字，寫入 terms.md，測試逐字比對 |
| B | 自由文字：reason 僅要求非空，測試只比對 ok 為 false 與 reason 非空 |
| C | 錯誤代碼加說明：reason 使用固定錯誤代碼，說明文字由呼叫端決定 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
`terms.md` 固定文案節、R-COUPON-002 與 R-COUPON-003 的 Then 步驟寫法、測試的比對強度。
