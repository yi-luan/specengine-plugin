# 釐清問題
一張不可疊加的券與一張或多張可疊加的券同時出現在同一次 `applyCoupons` 呼叫中時，應如何處理？需求第 4 條只說不可疊加券「一張訂單只能用一張」，未說明它能否與可疊加券併用。

# 定位
模組 COUPON｜Rule R-COUPON-006

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 允許併用：不可疊加券與可疊加券可同時套用 |
| B | 禁止併用：整次拒絕並回傳失敗原因 |
| C | 禁止併用：只套用不可疊加券，略過所有可疊加券 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
`applied` 的組成、`discount` 的計算、失敗原因的回傳。

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No

# 最終決策
- **決策選項**：不可疊加券與可疊加券併用時整筆拒絕，reason 為 `NOT_STACKABLE`（需求方回覆 9：不可疊加的券只能單獨用）
