# 釐清問題
一次結帳傳入多張券，其中一張不符合條件（已過期、未達最低消費、尚未生效）、其他券符合時，整次結果應如何？需求第 9 條只說「套用失敗時回傳失敗原因」，未區分整次失敗與部分套用。

# 定位
模組 COUPON｜Rule R-COUPON-002（同時影響 R-COUPON-003）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整次失敗：只要有一張不符合就回傳失敗原因，不套用任何券 |
| B | 部分套用：略過不符合的券，套用其餘券，並在結果中回報被略過的券 |
| C | 部分套用：略過不符合的券，套用其餘券，失敗原因不回傳（僅 applied 不含該券） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
`ApplyResult` 的成功與失敗判定、`applied` 的內容、是否需要新增被略過券的資訊欄位（目前結構只有 reason）。

# 優先級
High

Yes
