# 釐清問題
`orderAmount`（折扣前訂單金額）為負數、0、或非整數（例如 99.5）時，`applyCoupons` 應如何處理？需求第 12 條只說金額以整數元計算。

# 定位
模組 COUPON｜ApplyInput.orderAmount（影響所有 Rule 的輸入前提）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 負數與非整數一律回傳失敗；0 元訂單允許套用，折扣為 0 |
| B | 負數與非整數一律回傳失敗；0 元訂單也回傳失敗 |
| C | 非整數先截斷為整數再計算，負數回傳失敗 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
所有 Rule 的前提條件、失敗原因的回傳、測試的邊界案例（0 與負數）。
