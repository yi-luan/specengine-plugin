# 釐清問題（flow-align 疑似缺口 c）
百分比折扣算出 0 元（例如 1% × 50 元 = 0.5，無條件捨去為 0）時，該券是否仍列入 `applied`？矩陣未定義。

# 定位
模組 COUPON｜Rule R-COUPON-000（百分比計算結果）、新增 R-COUPON-019

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 列入 applied：券通過所有檢查即視為已套用，折扣為 0 |
| B | 不列入 applied：折扣為 0 視為未實際套用 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
`applied` 的組成、R-COUPON-019 的 Then 步驟、呼叫端對「已套用」的判定。

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
No

# 來源
spec-flow-align

---
# 最終決策
- **決策選項**：列入 applied（A）。需求方授權由 spec 代為判斷（回覆 1 (c)：「你決定，照你的最佳判斷」）。理由：`applied` 定義為「實際套用代碼」，券通過全部有效性與條件檢查即屬套用；折扣為 0 是計算結果，不是套用失敗，且不列入會使呼叫端無法得知該券已被接受
- **寫回位置**：矩陣 R-COUPON-019（新增）
