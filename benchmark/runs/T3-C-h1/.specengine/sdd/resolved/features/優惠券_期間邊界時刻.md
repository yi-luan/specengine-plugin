# 釐清問題
`now` 剛好等於有效起日（`valid_from`）或有效迄日（`valid_to`）這個時刻時，該券算不算在有效期間內？

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 含起迄：`valid_from <= now <= valid_to` 視為有效 |
