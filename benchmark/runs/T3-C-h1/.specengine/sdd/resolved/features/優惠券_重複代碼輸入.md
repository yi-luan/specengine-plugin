# 釐清問題
同一次 `applyCoupons` 呼叫的 `coupons` 清單中出現相同 `code` 的兩張券時（需求第 11 條規定同一租戶內代碼唯一），應如何處理？

# 定位
模組 COUPON｜Entity `coupons.code`（輸入清單的唯一性）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整次失敗，回傳失敗原因 |
| B | 去除重複，只保留第一次出現的券 |
| C | 不檢查，依傳入內容各自套用（可能重複折扣） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
`applied` 內容、`discount` 計算、輸入驗證邏輯。
