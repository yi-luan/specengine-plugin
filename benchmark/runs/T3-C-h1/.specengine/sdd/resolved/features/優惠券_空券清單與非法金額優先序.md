# 釐清問題（flow-align 疑似缺口 b、d）
沒有傳入任何券，且訂單金額為 0 時，結果是成功（R-COUPON-008）還是 INVALID_INPUT（R-COUPON-013）？另外，空清單成功的條件是否只限訂單金額為合法值？

# 定位
模組 COUPON｜Rule R-COUPON-008、R-COUPON-013（同時影響 R-COUPON-017 的檢查順序）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 依檢查順序：先檢查訂單金額，非法則 INVALID_INPUT；合法且無券才成功 |
| B | 空清單優先：無券即成功，不檢查訂單金額 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-COUPON-008 的前提、R-COUPON-013 的觸發條件（不再要求「有效券」）、R-COUPON-017 的檢查順序。
