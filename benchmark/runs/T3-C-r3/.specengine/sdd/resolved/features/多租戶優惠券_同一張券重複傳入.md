# 釐清問題
同一次結帳的優惠券清單中出現兩張代碼相同的券（同租戶內代碼唯一，所以代表同一張券被重複傳入），系統要怎麼處理？

# 定位
TENANT_COUPON：R-TENANT_COUPON-006、Coupon.code（同一租戶內代碼唯一）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆失敗，回報「優惠券重複」原因 |
| B | 自動去重：只套用第一次出現的那張，applied 只列一次 |
| C | 不特別處理，每一次都照常套用（可疊加券會被折兩次） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
重複代碼的檢查分支與測試案例、applied 清單內容
