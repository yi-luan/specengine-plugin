# 釐清問題
金額一律以整數元計算，但百分比折扣常算出小數（例如 999 元打 15% = 149.85 元）。折扣金額的小數要怎麼取整？

# 定位
TENANT_COUPON：R-TENANT_COUPON-001（百分比折扣計算）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 無條件捨去（149.85 → 149）：對商家有利，折扣絕不超過名目百分比 |
| B | 四捨五入（149.85 → 150；0.5 進位） |
| C | 無條件進位（149.85 → 150）：對顧客有利 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
百分比折扣金額、折扣總額與折扣後金額；所有含百分比折扣的測試案例

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
Yes

# 來源
spec-01

# 最終決策
- **決策選項**：A：每張 PERCENT 的折扣額各自無條件捨去取整數
