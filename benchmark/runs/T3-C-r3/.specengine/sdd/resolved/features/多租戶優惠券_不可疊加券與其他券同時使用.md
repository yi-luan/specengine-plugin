# 釐清問題
需求第 4 點「不可疊加的優惠券一張訂單只能用一張」有兩種讀法：(1) 用了不可疊加的券，這張訂單就不能再用任何其他券；(2) 不可疊加的券最多一張，但仍可再搭配可疊加的券。另外，傳入不符合規定的組合（例如兩張不可疊加、或不可疊加加上其他券）時系統要怎麼反應？

# 定位
TENANT_COUPON：R-TENANT_COUPON-007、Coupon.stackable

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 讀法 (1)：不可疊加的券只能單獨使用；只要傳入不可疊加券且總張數超過 1 張，整筆失敗並回報「不可疊加」原因 |
| B | 讀法 (1)，但不失敗：只套用傳入順序中第一張不可疊加的券，其餘券全部略過 |
| C | 讀法 (2)：最多一張不可疊加券，可與任意張可疊加券併用；出現兩張以上不可疊加券時整筆失敗並回報「不可疊加」原因 |
