# 釐清問題
套用失敗時回傳的「失敗原因」要用什麼固定文字？需求只說要回傳原因，沒有規定內容。測試與產品代碼需要逐字比對。

# 定位
TENANT_COUPON：ApplyResult.reason（R-TENANT_COUPON-003、004、005、007、008 等失敗情境）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 英文代碼（方便程式判斷）：租戶不符 `TENANT_MISMATCH`、尚未生效 `COUPON_NOT_STARTED`、已過期 `COUPON_EXPIRED`、未達最低消費 `MIN_ORDER_NOT_MET`、不可疊加衝突 `NOT_STACKABLE`，其他情境沿用同風格新增 |
| B | 中文文字（方便直接顯示）：「優惠券不屬於此租戶」「優惠券尚未生效」「優惠券已過期」「未達最低消費金額」「此優惠券不可與其他優惠券併用」，其他情境沿用同風格新增 |
| C | 英文代碼，但「尚未生效」與「已過期」合併為單一 `COUPON_NOT_IN_PERIOD` |
| Short | 自訂簡答 (<=5 字)，或直接提供整組文案 |
