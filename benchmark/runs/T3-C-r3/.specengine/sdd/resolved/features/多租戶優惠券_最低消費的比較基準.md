# 釐清問題
多張券疊加時，判斷某張券是否達到「最低消費金額」，要用哪個金額比較？例如訂單 1000 元，第一張先折 300 元，第二張券要求最低消費 800 元，第二張能不能用？

# 定位
TENANT_COUPON：R-TENANT_COUPON-005（最低消費判定）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 一律用折扣前的訂單金額比較（上例可用）；與「百分比以折扣前金額計算」一致 |
| B | 用套用前面券之後的剩餘金額比較（上例 700 < 800 不可用）；結果會受傳入順序影響 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-TENANT_COUPON-005 前置條件、疊加加最低消費的測試案例
