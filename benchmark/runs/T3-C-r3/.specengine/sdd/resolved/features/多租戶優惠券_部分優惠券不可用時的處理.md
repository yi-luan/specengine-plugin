# 釐清問題
一次傳入多張優惠券，其中有某張不可用（租戶不同、不在有效期間、未達最低消費）時，整筆結帳該怎麼回應？需求第 8、9 點同時提到「實際套用的優惠券代碼」與「套用失敗時回傳失敗原因」，無法判定是整筆失敗還是略過不可用的券。

# 定位
TENANT_COUPON：R-TENANT_COUPON-003、R-TENANT_COUPON-004、R-TENANT_COUPON-005（套用失敗處理）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆失敗：只要有任何一張不可用，就回傳失敗（ok: false）與失敗原因，所有券都不套用。行為最嚴格、最好理解 |
| B | 略過不可用的券：其餘可用的券照常套用並回傳成功，applied 只列實際套用者；不可用的券不回報原因。全部都不可用時也回傳成功、折扣 0 |
| C | 略過不可用的券，但若最後一張都沒套用成功，則回傳失敗與第一張不可用券的原因 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
applyCoupons 的回傳型態選擇（ok true/false）、R-003/004/005 的 post_assertions、多張券混合情境的所有測試案例
