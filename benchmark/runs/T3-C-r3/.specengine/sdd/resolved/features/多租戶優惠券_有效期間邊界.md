# 釐清問題
結帳時間剛好等於有效期間的起點或迄點那一刻，算不算在期間內？

# 定位
TENANT_COUPON：R-TENANT_COUPON-004（Coupon.validFrom／validTo 邊界）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 兩端都含：起點 ≤ 結帳時間 ≤ 迄點即可使用 |
| B | 含起不含迄：起點 ≤ 結帳時間 < 迄點（迄點那一刻已失效） |
| C | 兩端都不含：起點 < 結帳時間 < 迄點 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
有效期間判定、邊界測試案例

# 優先級
