# 釐清問題
需求第 6 點「固定金額折扣不得使訂單金額低於 0」沒說超過時系統要怎麼反應。例如訂單 100 元用 150 元的固定折扣券，或多張可疊加券（含百分比券，因為百分比都以折扣前金額計算，加總可能超過 100%）合計折扣超過訂單金額時，該怎麼辦？

# 定位
TENANT_COUPON：R-TENANT_COUPON-008（折扣上限）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 截斷：照常套用所有券並回傳成功，但折扣總額最多等於訂單金額，折扣後金額為 0；applied 列出所有傳入的券 |
| B | 拒絕：折扣總額超過訂單金額時整筆失敗，回報「折扣超過訂單金額」原因 |
| C | 依傳入順序逐張套用，折到 0 元為止；最後一張只折到剩餘金額，之後的券因為已無可折金額不列入 applied |
| Short | 自訂簡答 (<=5 字) |
