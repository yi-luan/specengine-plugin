# 釐清問題
同一次結帳同時存在多個問題（例如第一張券已過期、第二張租戶不符；或同一張券既過期又未達最低消費）時，失敗原因要回報哪一個？

# 定位
TENANT_COUPON：ApplyResult.reason（R-TENANT_COUPON-003、004、005 檢查順序）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 依傳入順序逐張檢查，回報第一張有問題的券；同一張券依「租戶 → 有效期間 → 最低消費」順序回報第一個不符項 |
| B | 先依檢查類別再依傳入順序：先檢查所有券的租戶，再檢查所有券的有效期間，再檢查最低消費，回報最先遇到的不符項 |
| C | 回報全部問題，多個原因以固定分隔符號串接成一個字串 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
產品代碼的檢查順序、多重違規情境測試的期望原因

Medium
