# 釐清問題
折抵上限是訂單金額的 30%，但金額與點數都是整數，訂單金額不是 10 的倍數時 30% 會算出小數（例如訂單 101 元 → 30.3）。上限應取多少？

# 定位
R-POINTS_REDEMPTION-000／002 的前置條件「折抵金額 <= 訂單金額的 30%」之計算方式；orders.order_amount × 30%；模組 POINTS_REDEMPTION

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 無條件捨去取整數（floor）：101 元上限 30 點，對商家保守 |
| B | 四捨五入（round）：101 元上限 30 點、105 元上限 32 點 |
| C | 無條件進位（ceil）：101 元上限 31 點，對會員寬鬆 |
| Short | 自訂簡答 (<=5 字) |
