# 釐清問題
會員要用的折抵點數超過自己的點數餘額時（例如餘額 100 點、想折 150 點），系統該怎麼反應？需求只寫「折抵成功後餘額要扣掉」，沒有定義餘額不足的情況。若為拒絕，失敗原因的固定文案是什麼？

# 定位
R-POINTS_REDEMPTION-000 的前置條件「折抵點數 <= 點數餘額」之反面；模組 POINTS_REDEMPTION

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕：回傳 ok=false 與固定失敗原因，餘額不變（請一併給失敗原因文案） |
| B | 自動折到餘額用完：以餘額為折抵點數繼續計算，回傳 ok=true |
| C | 其他（請說明） |
| Short | 自訂簡答 (<=5 字) |
