# 釐清問題

# 定位
R-POINTS_REDEMPTION-000 的零值邊界；模組 POINTS_REDEMPTION

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 算成功：ok=true，應付金額 = 訂單金額，剩餘點數 = 點數餘額（等同沒折抵） |
| B | 算失敗：ok=false 並回傳固定失敗原因（請一併給文案） |
| C | 其他（請說明） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
