# 釐清問題
同一筆折抵可能同時命中多個失敗條件（例如餘額 100 點、訂單 200 元、想折 150 點：既超過餘額又超過 30% 上限）。這時失敗原因要回報哪一個？需求只說「回傳失敗原因」（單數）。

# 定位
R-POINTS_REDEMPTION-001／002 及其他拒絕類 Rule 之間的優先序；模組 POINTS_REDEMPTION

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 固定檢查順序，回報第一個命中的原因（請一併給順序，例如：輸入非法 → 點數非法 → 點數不足 → 超過上限） |
| B | 回報所有命中的原因（reason 以固定分隔符串接） |
| C | 其他（請說明） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
所有拒絕類 Rule 的 pre_conditions 需加上「前序檢查皆通過」；實作的檢查順序；多重錯誤測試案例

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
No
