# 釐清問題
折抵金額超過訂單金額 30% 時（例如訂單 1000 元、想折 301 點），需求說「不得超過」且「不成功時回傳失敗原因」，但沒有明確寫系統反應是整筆拒絕還是自動修到上限，也沒有給失敗原因的文案。請確認反應方式與文案。

# 定位
