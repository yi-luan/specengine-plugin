# 釐清問題
折抵點數為負數（例如 -10）時系統該怎麼反應？需求已寫折抵點數必須是整數（非整數如 10.5 會不成功），但沒有提到負數，也沒有給非整數時的失敗原因文案。請確認負數的處理，以及負數與非整數各自（或共用）的失敗原因文案。

# 定位
R-POINTS_REDEMPTION-001（非整數）及其擴充（負數）；模組 POINTS_REDEMPTION

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 負數與非整數都拒絕，共用同一個固定失敗原因（請一併給文案） |
| B | 負數與非整數都拒絕，但用不同的失敗原因文案（請一併給兩個文案） |
| C | 其他（請說明） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-POINTS_REDEMPTION-001 的 pre_conditions／post_assertions；terms.md 固定文案；輸入驗證測試案例
