# 釐清問題
訂單金額或點數餘額本身不是整數（例如訂單 100.5 元、餘額 50.5 點）時系統該怎麼反應？需求說「金額與點數皆以整數元／整數點計算」，矩陣只定義了「訂單金額 <= 0 或點數餘額 < 0 → INVALID_INPUT」，非整數的情況沒有定義。

# 定位
R-POINTS_REDEMPTION-004（輸入非法）；PointsDiscountInput.orderAmount／pointsBalance；模組 POINTS_REDEMPTION

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 視同輸入非法：整筆拒絕，reason 沿用 INVALID_INPUT（與 R-004 同一關、同一文案） |
| B | 不驗證，視為呼叫端契約保證整數，範圍外 |
| C | 其他（請說明） |
| Short | 自訂簡答 (<=5 字) |
