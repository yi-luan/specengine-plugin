# 釐清問題
輸入的訂單金額為 0 或負數、或點數餘額為負數時，系統該怎麼反應？需求沒有定義這些非法輸入。若為拒絕，失敗原因的固定文案是什麼？

# 定位
PointsDiscountInput.orderAmount／pointsBalance 的輸入驗證；模組 POINTS_REDEMPTION

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 一律拒絕：回傳 ok=false 與固定失敗原因（請一併給文案） |
| B | 不驗證，照常計算（例如訂單 0 元則任何折抵都會超過 30% 上限而失敗） |
| C | 其他（請說明） |
| Short | 自訂簡答 (<=5 字) |
