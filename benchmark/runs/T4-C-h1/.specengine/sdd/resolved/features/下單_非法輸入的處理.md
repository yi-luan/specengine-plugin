# 釐清問題
需求第 9 條說「所有金額與數量都是整數」，但沒有說明收到數量為 0 或負數、金額為負數、或非整數時，placeOrder 要不要拒絕。

# 定位
MODULE_ID：EVENT_DRIVEN_ORDER；訂單服務的 placeOrder 輸入驗證，對應 CommandResult 的 ok:false 分支。

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕：回傳 ok:false 與原因，不建立訂單，不發出任何事件。 |
| B | 接受並進入流程：訂單照常建立，後續由庫存或付款自然失敗。 |
| Short | 自訂簡答（<=5 字） |

# 影響範圍
影響 placeOrder 的 CommandResult；影響是否需要「拒絕下單」的測試情境。
