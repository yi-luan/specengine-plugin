# 釐清問題
由於至少一次傳遞與客戶端重試，同一個 orderId 可能被 placeOrder 再次呼叫。需求沒有定義已存在的 orderId 再次下單時要怎麼處理。

# 定位
MODULE_ID：EVENT_DRIVEN_ORDER；訂單服務的 placeOrder，相關規則 R-EVENT_DRIVEN_ORDER-005（重複送達不產生額外效果）。

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕：回傳 ok:false，原因為訂單編號已存在，不發出任何事件。 |
| B | 冪等成功：回傳 ok:true，原有訂單不變，不發出新事件。 |
| Short | 自訂簡答（<=5 字） |

# 影響範圍
影響 placeOrder 的 CommandResult；影響 R-005 的重複送達規則是否延伸到命令層。

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
Yes（命令冪等性是通用工程議題）
