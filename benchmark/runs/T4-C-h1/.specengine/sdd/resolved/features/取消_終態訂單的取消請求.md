# 釐清問題
訂單已經是「庫存不足」「付款失敗」或「已取消」時，顧客又呼叫 cancelOrder，需求沒有說明結果。這個問題與「可取消的訂單狀態」相關，若該題答案為 A（只有處理中可取消），這題仍需要回答錯誤的回傳形式。

# 定位
MODULE_ID：EVENT_DRIVEN_ORDER；訂單服務的 cancelOrder，對應 CommandResult。

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 回傳 ok:false，附原因說明（例如訂單狀態不允許取消）。 |
| B | 回傳 ok:true，但不改狀態、不發出事件（冪等）。 |
| Short | 自訂簡答（<=5 字） |

# 影響範圍
影響 cancelOrder 的 CommandResult；影響測試中對終態訂單取消的斷言。
