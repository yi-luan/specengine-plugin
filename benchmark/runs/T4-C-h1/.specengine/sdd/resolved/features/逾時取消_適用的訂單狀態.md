# 釐清問題
需求第 7 條只說「沒有完成付款的訂單」要自動取消。「庫存不足」與「付款失敗」的訂單也沒有完成付款，但它們已經是終態。逾時判定要不要套用到這些狀態，需求沒有說明。

# 定位
MODULE_ID：EVENT_DRIVEN_ORDER；對應矩陣 R-EVENT_DRIVEN_ORDER-004 的 pre_conditions。

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 逾時只適用於「處理中」。「庫存不足」「付款失敗」維持原狀態，不發 OrderCancelled。 |
| B | 逾時適用於「處理中」「庫存不足」「付款失敗」。後兩者會轉為「已取消」，取消原因為 TIMEOUT，並發出 OrderCancelled。 |
| Short | 自訂簡答（<=5 字） |
