# 釐清問題
付款失敗時，庫存服務「放回庫存並發出 StockReleased」（需求第 5 條）。但取消訂單時（需求第 6 條），只寫「庫存服務放回保留的庫存」，沒有說明是否也要發出 StockReleased。

# 定位
MODULE_ID：EVENT_DRIVEN_ORDER；對應矩陣 R-EVENT_DRIVEN_ORDER-003 與 R-EVENT_DRIVEN_ORDER-004 的 post_assertions。

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 取消後庫存服務也發出 StockReleased，與付款失敗的放回事件一致，方便其他訂閱者追蹤庫存。 |
| B | 取消後庫存服務不發 StockReleased，OrderCancelled 已足夠，庫存服務內部放回即可。 |
| Short | 自訂簡答（<=5 字） |

# 影響範圍
影響 R-003、R-004 的 post_assertions；影響庫存服務事件清單與測試斷言。

# 最終決策
- **決策選項**：A（需求方 2026-11-01 回覆）。取消後庫存服務發出 StockReleased。補充：只放回實際保留的數量，同一張訂單最多放回一次；沒有保留過的訂單不加庫存、不發 StockReleased。
- **寫回位置**：矩陣 R-EVENT_DRIVEN_ORDER-002、-003、-004、-006 的 post_assertions；erm.dbml reservations.status（RELEASED 後不得再放回）
