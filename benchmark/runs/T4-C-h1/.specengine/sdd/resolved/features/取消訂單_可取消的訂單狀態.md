# 釐清問題
需求第 6 條寫「顧客可以取消訂單」，並說取消後要退還「已扣的款項」，但沒有說明訂單在哪些狀態下可以取消。目前可能的狀態有：處理中、已確認、庫存不足、付款失敗、已取消。

# 定位
MODULE_ID：EVENT_DRIVEN_ORDER；對應矩陣 R-EVENT_DRIVEN_ORDER-003（已確認訂單被取消），其餘狀態的取消行為尚未定義。

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 只有「處理中」可取消（付款前）。已確認之後不可取消，退款流程不存在。 |
| B | 「處理中」與「已確認」皆可取消。已確認者會全額退款。「庫存不足」「付款失敗」不可取消。 |
| C | 所有未取消的訂單皆可取消，含「庫存不足」「付款失敗」。沒有保留庫存或扣款的訂單只改狀態，不產生放回或退款。 |
| Short | 自訂簡答（<=5 字） |

# 影響範圍
影響矩陣 R-003 的 pre_conditions，以及訂單服務 cancelOrder 的合法狀態判斷；影響測試案例的數量與退款情境。
