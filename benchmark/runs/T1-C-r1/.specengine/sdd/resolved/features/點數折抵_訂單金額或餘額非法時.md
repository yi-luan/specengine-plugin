# 釐清問題
訂單金額是 0 或負數、或點數餘額是負數時，系統該怎麼反應？需求只說金額與點數以整數計算，沒有定義這些輸入是否合法。

# 定位
R-POINTS_REDEMPTION-（新 Rule）；PointsDiscountInput.orderAmount、pointsBalance；MODULE_ID = POINTS_REDEMPTION

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 一律拒絕並回傳失敗原因（訂單金額 ≤ 0 或餘額 < 0 都視為非法輸入） |
| B | 視為合法：訂單 0 元上限 0 點，餘額負數視同 0（容錯，但掩蓋呼叫端資料錯誤） |
| C | 訂單 0 元合法（上限 0 點）、負數金額與負數餘額拒絕 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
輸入驗證分支；若含拒絕需另定 reason 文案。
