# 釐清問題
會員折抵點數是負數（例如 -10 點）時怎麼辦？需求只寫「必須是整數」，負數也是整數，但折負數點等於加點，需求沒有定義。

# 定位
R-POINTS_REDEMPTION-（新 Rule）；PointsDiscountInput.pointsToUse；MODULE_ID = POINTS_REDEMPTION

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕並回傳失敗原因（防禦性輸入驗證） |
| B | 視同 0 點、折抵成功（容錯，但會默默吞掉呼叫端的錯誤） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
輸入驗證分支；若選 A 需另定 reason 文案。
