# 最終決策
- **決策選項**：B 「處理中」與「已確認」都可取消；已確認者取消後由庫存服務放回庫存、付款服務全額退款（需求方補充：已確認取消時 cancelReason 為 CUSTOMER，發 OrderCancelled；REJECTED／FAILED／CANCELLED 回 `NOT_CANCELLABLE`，不發事件）
