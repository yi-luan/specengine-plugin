# 釐清問題
餘額剛好等於訂單金額（例如餘額 100、訂單金額 100）時，要算「餘額足夠」還是「餘額不足」？

# 定位
PAYMENT：R-PAYMENT-001（邊界：收到 StockReserved 且餘額不足）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 視為足夠：扣款後餘額為 0，發出 PaymentSucceeded（判斷式為 餘額 >= 金額） |
| B | 視為不足：不扣款，發出 PaymentFailed（判斷式為 餘額 > 金額） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-PAYMENT-000 與 R-PAYMENT-001 的分界。
