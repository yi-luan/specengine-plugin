# 釐清問題
`OrderCancelled` 同樣可能重複送達。同一張訂單的第二次 `OrderCancelled` 抵達時，付款服務要怎麼處理？

# 定位
PAYMENT：R-PAYMENT-002（取消後全額退款）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 只退一次。重複的 OrderCancelled 不再退款，也不再發出任何事件 |
| B | 只退一次。重複的 OrderCancelled 不再退款，但重發一次 PaymentRefunded |
| C | 不做防重，每次收到都退款 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-PAYMENT-002 的前置條件與 post_assertions，新增 R-PAYMENT-004 的 OrderCancelled 部分。
