# 釐清問題
`createPaymentService(balances)` 只接收一份初始餘額表。如果收到 `StockReserved` 時，這位顧客不在餘額表中，付款服務要怎麼處理？

# 定位
PAYMENT：R-PAYMENT-000（主流程：收到 StockReserved 後扣款）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 視為餘額 0，餘額不足，走 PaymentFailed 流程 |
| B | 不處理：拋出錯誤、不發出任何事件 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-PAYMENT-001 的觸發條件，以及 getBalance 對未知顧客的回傳值。

Medium
