# 釐清問題
`OrderCancelled` 先於 `StockReserved` 抵達（事件亂序）。付款服務已記下這張訂單已取消，之後才收到 `StockReserved` 時，要不要扣款？

# 定位
PAYMENT：R-PAYMENT-005（未扣款訂單被取消）與新增的 R-PAYMENT-006

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 記住這張訂單已取消；之後到的 StockReserved 不扣款、不發任何事件 |
| B | 之後到的 StockReserved 照常扣款並發 PaymentSucceeded（顧客被扣款但訂單已取消，需要後續補償） |
| C | 拒絕這筆 StockReserved，發出 PaymentFailed |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-PAYMENT-005 的 post_assertions（記住已取消）、新增 R-PAYMENT-006。

# 優先級
High
