# 釐清問題
事件至少送達一次、可能重複。同一張訂單的 `StockReserved` 可能被付款服務收到兩次以上。第二次收到時，付款服務要怎麼處理？

# 定位
PAYMENT：R-PAYMENT-000（主流程：收到 StockReserved 後扣款）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 只扣一次。重複的 StockReserved 不再扣款，也不再發出任何事件 |
| B | 只扣一次。重複的 StockReserved 不再扣款，但重發一次 PaymentSucceeded |
| C | 不做防重，每次收到都扣款 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
新增 R-PAYMENT-004（同 id 重複事件忽略）。
