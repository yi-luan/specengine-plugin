# 釐清問題
已扣款且已退款的訂單，又收到另一個 id 不同的 `OrderCancelled`。R-PAYMENT-002 要求「尚未退款」，R-PAYMENT-005 只涵蓋「從未扣款」，這種情況沒有規則。要怎麼處理？

# 定位
PAYMENT：R-PAYMENT-005（未扣款或已退款的訂單被取消）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 不再退款，也不發任何事件（已退款就沒有可退的已扣款項） |
| B | 重發一次 PaymentRefunded（下游重試接收，但會讓下游看到兩次退款事件） |
| C | 拒絕並記錄警告，不發事件 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-PAYMENT-005 的 pre_conditions（改為「從未扣款，或已退款」）與 post_assertions。

High

# 最終決策
- **決策選項**：由執行者決定（需求方回覆：「(a)、(b)：你決定，照你的最佳判斷。」）。選 A。理由：不重複退款是 R-PAYMENT-002 的核心；不重發事件與 POLICY-001 同 id 忽略的精神一致，但此處 id 不同，故以「沒有可退的已扣款項」為判準，不靠事件 id。
- **寫回位置**：矩陣 R-PAYMENT-005 pre_conditions 與 post_assertions；resolved_by 指向本檔
