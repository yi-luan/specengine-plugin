# 釐清問題
會員折抵點數填 0（pointsToUse = 0）時，算折抵成功（金額不變、點數不扣）還是算失敗？需求沒有寫。

# 定位
R-POINTS_REDEMPTION-（新 Rule）；PointsDiscountInput.pointsToUse；MODULE_ID = POINTS_REDEMPTION

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 成功：finalAmount = 訂單金額、remainingPoints = 點數餘額（呼叫端不必特判 0） |
| B | 拒絕並回傳失敗原因（強制「有折才叫折抵」，呼叫端要先判斷是否呼叫） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
零值邊界 Scenario；若選 B 需另定 reason 文案。

# 優先級
Medium

# 可複用慣例候選 (Reusable Policy Candidate)
No
