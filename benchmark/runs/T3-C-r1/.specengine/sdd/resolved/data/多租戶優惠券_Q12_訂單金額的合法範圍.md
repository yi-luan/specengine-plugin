# 釐清問題
所有金額以整數元計算，但 orderAmount 是 number 型別，呼叫端可能傳 0、負數或小數。這些輸入要怎麼處理：拒絕（失敗原因固定文案為何？）、自動修正（例如捨去小數）、還是照算？訂單金額為 0 元時算合法嗎？

# 定位
ApplyInput.orderAmount（模組 MULTI_TENANT_COUPON）；R-MULTI_TENANT_COUPON-000

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 0、負數、非整數一律拒絕：ok = false 與固定失敗原因（請給文案，例如 `INVALID_INPUT`）。嚴格，呼叫端須先驗證 |
| B | 負數與非整數拒絕，但 0 元合法（折扣後仍為 0） |
| C | 非整數自動無條件捨去後照算，0 與負數拒絕 |
| Short | 自訂簡答 (<=5 字) |
