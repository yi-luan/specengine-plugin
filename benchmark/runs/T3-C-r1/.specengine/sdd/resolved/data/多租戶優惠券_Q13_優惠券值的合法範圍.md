# 釐清問題
優惠券本身的 value 可能不合法：PERCENT 的百分比超出 0～100（例如 0、150、負數）、FIXED 的金額 ≤ 0、或 value 不是整數。需求沒定義合法範圍，也沒說遇到不合法的券要怎麼處理。PERCENT 的合法範圍是多少（1～100？0～100？）？遇到不合法的券是整筆拒絕（固定文案？）還是略過？

# 定位
Coupon.value／coupons.value（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | PERCENT 合法範圍 1～100 整數、FIXED 必須 > 0 整數；不合法時整筆拒絕，ok = false 與固定失敗原因（請給文案，例如 `INVALID_COUPON`） |
| B | PERCENT 合法範圍 0～100、FIXED ≥ 0（允許 0 折扣的券）；不合法時整筆拒絕 |
| C | 不驗證券值，照算（信任資料層已保證合法） |
| D | 不合法的券略過，其餘照常套用 |
| Short | 自訂簡答 (<=5 字) |
