# 釐清問題
券的 validFrom／validTo 不是合法的 ISO 8601 時間（例如空字串、"abc"），或 validFrom 晚於 validTo（期間顛倒）；或結帳時間 now 不是合法時間。這些情況目前矩陣沒有對應結果。要怎麼處理？

# 定位
Coupon.validFrom／validTo、ApplyInput.now（模組 MULTI_TENANT_COUPON）；R-MULTI_TENANT_COUPON-003、R-MULTI_TENANT_COUPON-017、R-MULTI_TENANT_COUPON-015

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 券的時間不合法或期間顛倒 → 視為券值不合法，整筆拒絕 `INVALID_COUPON`；now 不合法 → 視為輸入不合法，整筆拒絕 `INVALID_INPUT`。沿用既有代碼與檢查順序 |
| B | 券的時間不合法或期間顛倒 → 視為不在有效期間，整筆拒絕 `COUPON_EXPIRED`；now 不合法 → `INVALID_INPUT` |
| C | 不驗證，信任呼叫端（時間不合法時行為未定義） |
| Short | 自訂簡答 (<=5 字) |
