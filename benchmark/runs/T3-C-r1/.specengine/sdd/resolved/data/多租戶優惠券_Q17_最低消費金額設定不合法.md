# 釐清問題
券的最低消費金額 minOrderAmount 設成負數、0 或非整數（例如 -100、0、99.5）。先前「券值不合法」（Q13）只涵蓋折扣值 value，沒涵蓋最低消費金額。這些情況要怎麼處理？

# 定位
Coupon.minOrderAmount／coupons.min_order_amount（模組 MULTI_TENANT_COUPON）；R-MULTI_TENANT_COUPON-017、R-MULTI_TENANT_COUPON-007

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 負數或非整數 → 券值不合法，整筆拒絕 `INVALID_COUPON`；0 視為合法（等同無門檻） |
| B | 負數、0、非整數一律 → 整筆拒絕 `INVALID_COUPON`（有設定就必須是正整數） |
| C | 不驗證，照比較（負數或 0 自然等同無門檻） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-017 的 pre_conditions；erm.dbml coupons.min_order_amount note；applyCoupons 的券值驗證
