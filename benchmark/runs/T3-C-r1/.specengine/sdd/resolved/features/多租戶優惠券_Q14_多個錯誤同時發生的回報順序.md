# 釐清問題
一次結帳可能同時命中多種失敗情況（例如一張券屬於別的租戶、另一張又過期、同時訂單又未達最低消費）。需求說「套用失敗時回傳失敗原因」（單數）。要回報哪一個？檢查的先後順序是什麼？

# 定位
ApplyResult.reason（模組 MULTI_TENANT_COUPON）；R-MULTI_TENANT_COUPON-002～007

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 固定檢查順序，回報第一個命中的原因（請指定順序；建議：輸入合法性 → 券值合法性 → 租戶 → 重複 → 期間 → 最低消費 → 疊加 → 折扣超過訂單金額） |
| B | 依傳入券的順序逐張檢查，回報第一張有問題的券的原因（同一張券內再依固定順序） |
| C | 回報所有原因（需擴充回傳型別為陣列，與固定介面衝突） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
所有拒絕類 Rule 的 pre_conditions（需保證每個 Scenario 只命中一種錯誤）；applyCoupons 的檢查順序；多重錯誤的 Scenario
