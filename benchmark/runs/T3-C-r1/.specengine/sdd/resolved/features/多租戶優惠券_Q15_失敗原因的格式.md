# 釐清問題
ApplyResult.reason 是 string，需求沒說格式：是給程式判斷用的固定代碼（例如 `TENANT_MISMATCH`），還是給人看的中文句子（例如「優惠券不屬於此租戶」），還是「代碼：說明」混合？這決定了 .feature 裡 Then 要逐字比對的文案。

# 定位
ApplyResult.reason（模組 MULTI_TENANT_COUPON）；terms.md 固定文案

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 固定的全大寫英文代碼（SNAKE_CASE），每種失敗一個；呼叫端自行對應顯示文字。穩定、可程式判斷 |
| B | 固定的繁體中文句子；直接可顯示，但呼叫端難以程式判斷 |
| C | 「代碼: 中文說明」的混合字串 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
terms.md 固定文案節；所有拒絕類 Rule 的 post_assertions；Then 步驟的逐字比對
