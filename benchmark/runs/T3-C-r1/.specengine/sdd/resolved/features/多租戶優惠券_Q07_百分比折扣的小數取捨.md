# 釐清問題
所有金額以整數元計算，但百分比折扣算出來可能有小數（例如 333 元打 10% = 33.3 元）。小數要怎麼取捨？多張百分比券時，是每張各自取整後再加總，還是加總後再取整？

# 定位
R-MULTI_TENANT_COUPON-001、R-MULTI_TENANT_COUPON-005（模組 MULTI_TENANT_COUPON）；ApplyResult.discount

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 每張 PERCENT 的折扣額各自無條件捨去（floor）取整數，再加總。對商家有利，可預測 |
| B | 每張 PERCENT 的折扣額各自四捨五入（round）取整數，再加總 |
| C | 每張 PERCENT 的折扣額各自無條件進位（ceil）取整數，再加總。對消費者有利 |
| D | 所有 PERCENT 折扣額先以小數加總，最後一次取整（請指定取整方式） |
| Short | 自訂簡答 (<=5 字) |
