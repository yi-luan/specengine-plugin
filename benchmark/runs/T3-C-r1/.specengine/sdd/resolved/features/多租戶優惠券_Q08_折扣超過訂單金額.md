# 釐清問題
需求說「固定金額折扣不得使訂單金額低於 0」。當折扣總額（單張固定金額券、或多張券加總）超過訂單金額時，系統是整筆拒絕，還是自動截斷讓折扣後金額為 0？折扣總額「剛好等於」訂單金額（折扣後金額剛好 0 元）可不可以？若拒絕，失敗原因的固定文案是什麼？

# 定位
R-MULTI_TENANT_COUPON-006（模組 MULTI_TENANT_COUPON）；ApplyResult.finalAmount／reason

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 超過時整筆拒絕（請給固定文案，例如 `DISCOUNT_EXCEEDS_AMOUNT`）；剛好等於可以，折扣後金額 = 0 |
| B | 超過時整筆拒絕；剛好等於也拒絕（折扣後金額必須 > 0） |
| C | 超過時自動截斷：折扣總額 = 訂單金額，折扣後金額 = 0，ok = true |
| Short | 自訂簡答 (<=5 字) |
