# 釐清問題
多張可疊加的券同時使用時，折扣總額怎麼算？需求已固定「百分比折扣一律以折扣前的訂單金額計算」，所以多張百分比券不會互相影響；但多張百分比與固定金額混在一起時，是「各自對原始訂單金額算出折扣額後直接加總」，還是有其他順序（例如先算百分比再扣固定金額、或先扣固定再算百分比——後者已被需求排除）？

# 定位
R-MULTI_TENANT_COUPON-005（模組 MULTI_TENANT_COUPON）；ApplyResult.discount

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 各自獨立計算後加總：每張 PERCENT 以原始訂單金額算出折扣額，所有 FIXED 直接取其金額；折扣總額 = 全部折扣額之和，折扣後金額 = 訂單金額 − 折扣總額。最簡單、與傳入順序無關 |
| B | 依傳入順序逐張套用，PERCENT 仍以原始訂單金額計算、FIXED 依序扣減；結果與 A 數學上相同，但實作需保留順序（主要影響「折扣總額超過訂單金額」時哪一張先被判定） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-MULTI_TENANT_COUPON-005 的 post_assertions；applyCoupons 的折扣加總邏輯；與 Q08（折扣超過訂單金額）的判定方式連動
