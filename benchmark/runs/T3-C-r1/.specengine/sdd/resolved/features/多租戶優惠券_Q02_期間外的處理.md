# 釐清問題
結帳時傳入的優惠券裡，有一張已過期（now 晚於 validTo）或尚未生效（now 早於 validFrom）。需求只說「只能在期間內使用」，沒說整筆結帳要怎麼回應：整筆失敗，還是只略過那一張？若整筆失敗，失敗原因的固定文案是什麼？「過期」與「尚未生效」要不要分成兩個不同的原因？

# 定位
R-MULTI_TENANT_COUPON-003（模組 MULTI_TENANT_COUPON）；ApplyResult.reason

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕，過期與未生效共用同一個固定失敗原因（請一併給文案，例如 `COUPON_EXPIRED`） |
| B | 整筆拒絕，過期與未生效各自有不同的固定失敗原因（請給兩個文案） |
| C | 略過該券，其餘有效券照常套用，ok = true |
| Short | 自訂簡答 (<=5 字) |
