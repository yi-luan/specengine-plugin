# 釐清問題
一次結帳傳入兩張以上「不可疊加」的優惠券。需求說「不可疊加的優惠券一張訂單只能用一張」，但沒說這時系統要整筆拒絕，還是自動只用其中一張（用哪一張？）。若整筆拒絕，失敗原因的固定文案是什麼？

# 定位
R-MULTI_TENANT_COUPON-004（模組 MULTI_TENANT_COUPON）；ApplyResult.reason

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕：ok = false 與固定失敗原因（請一併給文案，例如 `NOT_STACKABLE`）。呼叫端必須自己挑一張 |
| B | 只套用傳入順序的第一張不可疊加券，其餘略過，ok = true |
| C | 只套用折扣最大的那一張不可疊加券，其餘略過，ok = true（需先算折扣再比較） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
