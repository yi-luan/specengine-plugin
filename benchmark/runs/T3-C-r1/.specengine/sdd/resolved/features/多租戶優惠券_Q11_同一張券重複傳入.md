# 釐清問題
同一張優惠券（同 tenantId + 同 code）在 coupons 陣列裡出現兩次。需求說「同一租戶內優惠券代碼唯一」，但那是資料約束；結帳時重複傳入要怎麼處理：整筆拒絕、只算一次、還是算兩次？若拒絕，失敗原因的固定文案是什麼？

# 定位
R-MULTI_TENANT_COUPON-005（模組 MULTI_TENANT_COUPON）；coupons.(tenant_id, code) 唯一；ApplyResult.reason

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕：ok = false 與固定失敗原因（請給文案，例如 `DUPLICATE_COUPON`）。輸入明顯有誤，不猜 |
| B | 去重後只套用一次，ok = true，applied 只列一次 |
| C | 照傳入次數重複套用（可疊加時折兩次） |
| Short | 自訂簡答 (<=5 字) |
