# 釐清問題
一次結帳傳入「一張不可疊加」加上「一張以上可疊加」的優惠券。需求只定義了「不可疊加的券一張訂單只能用一張」和「可疊加的可以多張同時用」，沒說兩種混在一起時能不能一起用：不可疊加的券是「只能跟其他不可疊加的券互斥」，還是「只能單獨使用、不能跟任何券同用」？

# 定位
R-MULTI_TENANT_COUPON-004、R-MULTI_TENANT_COUPON-005（模組 MULTI_TENANT_COUPON）

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 不可疊加的券只能單獨使用：混用時整筆拒絕，失敗原因與 Q04 相同的固定文案（例如 `NOT_STACKABLE`） |
| B | 可以混用：一張不可疊加 + 多張可疊加一起套用，只有「兩張以上不可疊加」才違規 |
| C | 混用時略過不可疊加那張，只套用可疊加的券，ok = true |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-MULTI_TENANT_COUPON-004／005 的 pre_conditions 與 post_assertions；applyCoupons 的疊加檢查

High
