# 釐清問題
最低消費金額是用「折扣前的訂單金額」還是「折扣後的金額」來判定？訂單金額「剛好等於」最低消費金額算不算達標？未達時是整筆拒絕還是只略過那張券？若拒絕，失敗原因的固定文案是什麼？

# 定位
R-MULTI_TENANT_COUPON-007、R-MULTI_TENANT_COUPON-008（模組 MULTI_TENANT_COUPON）；coupons.min_order_amount

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 以折扣前訂單金額判定；等於算達標（orderAmount ≥ minOrderAmount）；未達時整筆拒絕（請給固定文案，例如 `MIN_ORDER_NOT_MET`） |
| B | 以折扣前訂單金額判定；等於算達標；未達時只略過該券，其餘照常套用 |
| C | 以折扣後金額判定（需先算其他券的折扣，多張券時判定順序會互相影響） |
| D | 以折扣前訂單金額判定；等於不算達標（orderAmount > minOrderAmount） |
| Short | 自訂簡答 (<=5 字) |
