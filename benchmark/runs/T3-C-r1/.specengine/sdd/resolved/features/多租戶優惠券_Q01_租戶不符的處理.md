# 釐清問題
結帳時傳入的優惠券裡，有一張屬於別的租戶（Coupon.tenantId 與訂單的 tenantId 不同）。需求只說「優惠券只能用在同一租戶的訂單」，沒說這時整筆結帳要怎麼回應：是整筆失敗（ok = false），還是只略過那一張、其餘照常套用？若整筆失敗，失敗原因的固定文案是什麼？

# 定位
R-MULTI_TENANT_COUPON-002（模組 MULTI_TENANT_COUPON）；ApplyResult.reason

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 整筆拒絕：回傳 ok = false 與固定失敗原因（請一併給文案，例如 `TENANT_MISMATCH`）。最保守，呼叫端必須修正輸入 |
| B | 略過該券：其餘有效券照常套用，applied 不含該券，ok = true。較寬鬆，但呼叫端看不出有券被丟掉 |
| C | 略過該券並在結果附帶警告清單（需擴充回傳型別，與固定介面衝突） |
| Short | 自訂簡答 (<=5 字) |
