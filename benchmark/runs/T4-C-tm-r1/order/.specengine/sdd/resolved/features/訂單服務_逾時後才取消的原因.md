# 釐清問題
取消訂單的介面帶有取消時間 `at`。若顧客取消的時間點已經超過下單後 15 分鐘，但整合端還沒有推進時間（tick）去觸發自動取消，訂單此時仍是「處理中」。這筆取消要算誰的？

# 定位
R-ORDER_SERVICE-004（取消訂單）、R-ORDER_SERVICE-005（逾時自動取消）、orders.cancel_reason；模組 ORDER_SERVICE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 以實際動作為準：記為顧客取消（CUSTOMER），發出 OrderCancelled；取消時間只記錄、不拿來判定逾時 |
| B | 先結算逾時：取消時間已超過 15 分鐘就記為逾時（TIMEOUT），發出 OrderCancelled，回傳 ok:true |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-ORDER_SERVICE-004 的取消原因；cancelOrder 參數 at 的用途；cancelOrder 的測試案例
