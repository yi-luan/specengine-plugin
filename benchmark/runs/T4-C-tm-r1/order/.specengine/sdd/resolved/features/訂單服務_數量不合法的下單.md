# 釐清問題
需求第 9 點只說「所有金額與數量都是整數」，沒有說數量的下限，也沒有說收到不合法數量（0、負數、非整數如 1.5）時訂單服務該怎麼反應。數量的合法範圍是什麼？超出時怎麼處理？

# 定位
R-ORDER_SERVICE-000（下單）、orders.qty；模組 ORDER_SERVICE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 數量必須是 ≥ 1 的整數；否則拒絕：回傳 ok:false，原因文字「數量不合法」，不建立訂單、不發事件 |
| B | 數量必須是 ≥ 0 的整數（允許 0 件）；負數或非整數才拒絕，原因文字「數量不合法」 |
| C | 不檢查：照單全收，數量原樣寫入訂單與 OrderPlaced（交由庫存服務判斷） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-ORDER_SERVICE-000 的前置條件與失敗分支；placeOrder 的 Scenario Outline 邊界列；選 A／B 時新增固定文案
