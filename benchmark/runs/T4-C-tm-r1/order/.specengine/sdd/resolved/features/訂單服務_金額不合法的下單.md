# 釐清問題
需求第 9 點只說金額是整數，沒有說金額的下限（0 元訂單可不可以？）也沒有說收到負數或非整數金額時訂單服務該怎麼反應。金額的合法範圍是什麼？超出時怎麼處理？

# 定位
R-ORDER_SERVICE-000（下單）、orders.amount；模組 ORDER_SERVICE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 金額必須是 ≥ 1 的整數；否則拒絕：回傳 ok:false，原因文字「金額不合法」，不建立訂單、不發事件 |
| B | 金額必須是 ≥ 0 的整數（允許 0 元訂單）；負數或非整數才拒絕，原因文字「金額不合法」 |
| C | 不檢查：照單全收，金額原樣寫入訂單與 OrderPlaced（交由付款服務判斷） |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-ORDER_SERVICE-000 的前置條件與失敗分支；placeOrder 的 Scenario Outline 邊界列；選 A／B 時新增固定文案
