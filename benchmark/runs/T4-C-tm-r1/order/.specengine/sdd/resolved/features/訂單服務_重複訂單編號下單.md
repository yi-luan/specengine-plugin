# 釐清問題
顧客用一個已經存在的訂單編號再次下單（例如前端重送、或訂單已取消後想用同一編號重下）。訂單服務該怎麼回應？

# 定位
R-ORDER_SERVICE-000（下單）、orders.order_id；模組 ORDER_SERVICE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕：回傳 ok:false，原因文字「訂單編號重複」，既有訂單不變、不發事件 |
| B | 冪等：回傳 ok:true 且 events 為空陣列，既有訂單不變、不再發 OrderPlaced |
| C | 覆蓋：以新的輸入取代舊訂單，狀態重設為「處理中」並再發一次 OrderPlaced |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-ORDER_SERVICE-000 的前置條件「訂單編號尚未被使用」的失敗分支；placeOrder 的測試案例；選 A 時新增固定文案

High
