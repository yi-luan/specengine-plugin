# 釐清問題
訂單已經因「庫存不足」（REJECTED）或「付款失敗」（FAILED）結束時，顧客仍送出取消要求。這類訂單沒有保留中的庫存、也沒有扣款，訂單服務應該怎麼回應？

# 定位
R-ORDER_SERVICE-004（取消訂單）、orders.status；模組 ORDER_SERVICE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 拒絕：回傳 ok:false，原因文字「訂單已結束，無法取消」，狀態維持原樣（庫存不足／付款失敗），不發事件 |
| B | 接受並轉為已取消：狀態改為「已取消」（原因 CUSTOMER），發出 OrderCancelled（庫存／付款服務收到後可自行判斷無事可做） |
| C | 接受但不動：回傳 ok:true 且 events 為空陣列，狀態維持原樣 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-ORDER_SERVICE-004 的前置條件與失敗分支；cancelOrder 的測試案例；選 A 時新增固定文案
