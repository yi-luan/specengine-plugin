# 釐清問題
「沒有完成付款」字面上也包含已經因「庫存不足」或「付款失敗」而結束的訂單。時間推進超過 15 分鐘時，哪些狀態的訂單要被自動取消？

# 定位
R-ORDER_SERVICE-005（逾時自動取消）、orders.status；模組 ORDER_SERVICE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 只有「處理中」的訂單會被逾時取消；「庫存不足」「付款失敗」是已結束的最終狀態，不再改動、不發事件 |
| B | 「處理中」「庫存不足」「付款失敗」都會在逾時後改為「已取消」（原因 TIMEOUT）並各發出 OrderCancelled |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-ORDER_SERVICE-005 的前置條件；tick 的測試案例（已結束訂單在逾時後的狀態）

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No

spec-01

# 最終決策
- **決策選項**：A — 只有「處理中」會被逾時取消；其他狀態不改動、不發事件（使用者補充：以訂單服務當下的狀態判定）
- **寫回位置**：矩陣 R-ORDER_SERVICE-005（post_assertions 增列其他狀態不受影響）
