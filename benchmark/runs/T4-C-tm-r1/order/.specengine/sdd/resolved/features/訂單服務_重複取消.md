# 釐清問題
訂單已經是「已取消」（不論是顧客取消或逾時自動取消），顧客又再送一次取消要求（例如快速連點、或在逾時後才按取消）。訂單服務應該怎麼回應？

# 定位
R-ORDER_SERVICE-004（取消訂單）、orders.status = CANCELLED；模組 ORDER_SERVICE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 冪等成功：回傳 ok:true 且 events 為空陣列，狀態與原本的取消原因不變、不再發 OrderCancelled |
| B | 拒絕：回傳 ok:false，原因文字「訂單已取消」，狀態不變、不發事件 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-ORDER_SERVICE-004 的重複觸發分支；cancelOrder 的測試案例；選 B 時新增固定文案

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
Yes

# 最終決策
- **決策選項**：Short（自訂）— 已取消的訂單不能再取消，回 { ok: false, reason: 'NOT_CANCELLABLE' }，狀態不變、不發事件
