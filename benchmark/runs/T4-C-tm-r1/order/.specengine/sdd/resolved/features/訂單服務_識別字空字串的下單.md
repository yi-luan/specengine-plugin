# 釐清問題
下單輸入的訂單編號、顧客、商品 SKU 都是字串，需求沒有說空字串算不算合法。收到空字串（例如訂單編號為 ""）時訂單服務該怎麼反應？

# 定位
R-ORDER_SERVICE-000（下單）、orders.order_id、orders.customer_id、orders.sku；模組 ORDER_SERVICE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 三者皆不可為空字串；否則拒絕：回傳 ok:false，原因文字「欄位不可為空」，不建立訂單、不發事件 |
| B | 不檢查：照單全收 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-ORDER_SERVICE-000 的前置條件與失敗分支；placeOrder 的測試案例；選 A 時新增固定文案

# 優先級
Low

# 可複用慣例候選 (Reusable Policy Candidate)
No

# 最終決策
- **決策選項**：Short（自訂）— orderId／customerId／sku 為空字串一律拒絕，reason 固定為 INVALID_INPUT，不建立訂單、不發事件
- **寫回位置**：矩陣 R-ORDER_SERVICE-000（pre_conditions 增列非空字串）、R-ORDER_SERVICE-012（新增）；terms.md 固定文案 MSG-004
