# 釐清問題
需求第 6 點說「顧客可以取消訂單」，並說取消後付款服務要退款，但沒有說明付款已成功、訂單已是「已確認」時，顧客還能不能取消。訂單服務收到對「已確認」訂單的取消要求時，應該怎麼做？

# 定位
R-ORDER_SERVICE-004（取消訂單）、orders.status；模組 ORDER_SERVICE

# 多選題選項
| 選項 | 描述 (工程 Trade-off) |
|---|---|
| A | 可以取消：狀態改為「已取消」（CANCELLED，原因 CUSTOMER），發出 OrderCancelled，讓付款服務退款、庫存服務放回庫存 |
| B | 不可以取消：回傳 ok:false，原因文字「訂單已確認，無法取消」，狀態不變、不發事件 |
| Short | 自訂簡答 (<=5 字) |

# 影響範圍
R-ORDER_SERVICE-004 的前置條件（可取消的狀態集合）；cancelOrder 的測試案例；選 B 時新增固定文案

# 優先級
High

# 可複用慣例候選 (Reusable Policy Candidate)
No

# 最終決策
- **決策選項**：A — 可以取消：狀態改為已取消，cancelReason 為 CUSTOMER，發出 OrderCancelled（使用者補充：已確認取消時 cancelReason 為 CUSTOMER）
- **寫回位置**：矩陣 R-ORDER_SERVICE-004（pre_conditions 擴為「處理中」或「已確認」）
